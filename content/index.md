# 👋 你好！

这里是我的个人知识库（Digital Garden），用于记录学习、技术探索和生活感悟。

本站点由 **Obsidian** 驱动，通过 **Quartz** 构建，内容与我的本地笔记库中的公开文件夹保持同步。

### 🧭 如何浏览？

* **👈 左侧导航栏**：使用左侧的文件资源管理器 (Explorer)，可以直接浏览所有的文件夹和笔记。
* **🔍 全局搜索**：点击左上角的搜索图标（或按 `Ctrl + k`），可以快速查找关键词。
* **🕸️ 知识图谱**：点击右侧的图谱，查看知识点之间的关联。
