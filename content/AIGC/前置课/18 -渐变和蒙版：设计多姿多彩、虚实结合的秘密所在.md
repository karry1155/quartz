### 🔑 核心逻辑与快捷键表

|**功能模块**|**核心口诀/逻辑**|**关键操作/快捷键**|
|---|---|---|
|**内部绘图**|"画在肚子里"|工具栏底部第三个按钮 (Draw Inside)|
|**剪切蒙版**|**上切下** (路径在顶层)|右键 -> 建立剪切蒙版 (`Ctrl+7`)|
|**复杂裁切**|多个形状变一个|选中多个形状 -> `Ctrl+8` 建立复合路径|
|**透明度蒙版**|**黑透白不透** (灰半透)|窗口 -> 透明度面板 -> 制作蒙版|
|**编辑状态**|**进得去要出得来**|点击蒙版缩略图编辑，点击对象缩略图退出|

### 🚨 避坑指南 (Don't Do This)

- ❌ **切忌惯性思维**：不要像 PS 那样把蒙版放在底层！**AI 中蒙版路径必须在最顶层**。
    
- ❌ **切忌直接用编组做蒙版**：如果想用一组图形（如蜂巢）去裁切图片，直接建立会失败。**必须先按 `Ctrl+8` 转为复合路径**。
    
- ❌ **切忌“迷路”**：在透明度蒙版编辑模式下（图层面板只有蒙版），**切记点回左侧对象缩略图**才能继续编辑主画面，否则你会发现选中不了任何东西。

## 📺 视频全案复盘 (沉浸式学习)

### 📍 00:57 内部绘图模式 (Draw Inside)

- **核心概念**：不仅有“正常绘图”和“背面绘图”，AI 还有一个神器叫“内部绘图”。它能自动生成**剪切组**，把新画的内容限制在选中对象的范围内。
    
- **操作步骤**：
    
    1. 选中一个闭合路径（如背景矩形）。
        
    2. 点击工具栏底部的 **内部绘图按钮**（图形周围出现虚线框标记）。
        
    3. 切换画笔或置入素材，在框内任意涂抹。
        
    4. _结果_：所有内容自动被“关”进矩形里，移动矩形时内容会跟随。
        
- _老师说_：“一句话概括，正常的模式是一层层往上叠，而这个内部绘图模式，就是把东西装进这个形状的‘肚子’里，再也不怕元素跑出画板了。”
    

### 📍 04:17 手动建立剪切蒙版

- **核心概念**：利用一个形状（蒙版）来限制另一个对象（被蒙版）的显示范围。
    
- **操作指南**：
    
    1. **准备素材**：一个容器形状（如圆形），一个内容（如文字）。
        
    2. **调整层级**：**务必确保容器形状在图层最上方**（覆盖住内容）。
        
    3. **建立蒙版**：同时选中两者 -> 右键 -> **建立剪切蒙版**。
        
    4. **调整**：双击进入隔离模式，可以独立移动内容或修改容器形状。
        
- _老师说_：“即便你把顺序搞反了，文字在上面，那文字就变成了蒙版，下面的色块就变成了内容。AI 是非常讲究长幼尊卑（层级顺序）的。”
    

### 📍 09:06 进阶：复合路径做蒙版

- **痛点解决**：想把图片放进一个由很多六边形组成的“蜂巢”里，直接做蒙版会失败。
    
- **操作步骤**：
    
    1. 绘制多个六边形，拼成蜂巢图案。
        
    2. 选中所有六边形，按下 **`Ctrl+8` (建立复合路径)**，告诉 AI 这是一个整体。
        
    3. 将复合路径置于图片上方 -> 建立剪切蒙版。
        

### 📍 12:35 透明度蒙版 (Transparency Mask)

- **核心概念**：AI 版的“图层蒙版”。不再是“非黑即白”的硬裁切，而是利用灰度实现**半透明、羽化、渐隐**效果。
    
- **操作步骤**：
    
    1. 选中对象，打开 **[透明度] 面板**。
        
    2. 点击 **[制作蒙版]**（对象旁出现黑色或白色方块）。
        
    3. **点击蒙版缩略图**进入编辑模式（此时只能编辑蒙版）。
        
    4. 绘制形状并填充 **黑/白/灰** 或 **黑白渐变** 来控制显示。
        
    5. **重要**：如果不显示，检查面板上的“剪切”和“反向蒙版”勾选状态（通常默认勾选“剪切”会让背景变黑，需画白色才显示）。
        

### 📍 18:18 渐变在蒙版中的应用

- **核心技巧**：做“文字倒影”或“气泡渐隐”。
    
- **实操案例（断裂文字）**：
    
    1. 用美工刀工具将文字切成三段，拉开距离。
        
    2. 为下方文字段建立透明度蒙版。
        
    3. 在蒙版中绘制一个 **黑到白（90度垂直）** 的矩形。
        
    4. 调整渐变滑块，实现文字断裂处的平滑消失。
        
- _老师说_：“如果蒙版控制得不干净，检查一下你的黑色是不是**纯黑（K100）**，或者颜色模式是否与文档一致。”
    

### 📍 23:28 案例：星球环带的非破坏性隐藏

- **设计难点**：画土星环时，前段要挡住星球，后段要被星球挡住。
    
- **解决方案**：
    
    1. 绘制扁椭圆作为环带。
        
    2. 建立透明度蒙版，在蒙版里画一个矩形。
        
    3. 给矩形填充 **白-黑-白** 的线性渐变。
        
    4. 利用黑色区域遮住环带绕到星球背后的那一段，实现非破坏性遮挡（不用剪断路径）。
        

### 📍 26:34 综合案例：扁平风景插画

- **落日渐隐**：复制落日圆 -> 透明度蒙版 -> 黑白渐变（下半部消隐入云层）。
    
- **落日发光**：复制落日圆放大 -> 填充橘红色 -> **混合模式改为[滤色/Screen]** -> 镜像渐变。
    
- **山体阴影**：选中山体 -> **内部绘图模式** -> 用钢笔画出锯齿状阴影区 -> 填充黑色 -> 混合模式[叠加] -> 透明度30%。
    
- **水面倒影**：复制山景 -> **垂直翻转** -> 建立剪切蒙版限制在水面区域 -> 降低不透明度 + 叠加渐变蒙版做渐隐。
