# 🚀 告别“手残党”：用圆圈和布尔运算，在AI里“算”出完美插画

> 前言：
> 
> 你是否觉得在AI里手绘图形很难控制线条的平滑度？或者面对复杂的图标（如太极、Logo）不知从何下笔？其实，很多看似复杂的图形根本不是“画”出来的，而是“算”出来的！这节课我们将深入AI的图形绘制核心——路径查找器（布尔运算）与形状生成器，教你如何用简单的几何图形“拼”出大师级作品。哪怕你没有任何美术功底，也能通过这套逻辑做出精准、圆润的矢量插画。

## ⚡ 核心知识速查 (Cheat Sheet)

### 🔑 关键操作/快捷键表

| **功能/工具**    | **快捷键/操作**           | **核心作用**                          |
| ------------ | -------------------- | --------------------------------- |
| **原位粘贴**     | `Ctrl` + Shift `+ V` | 复制图形后，精准粘贴在原坐标位置（太极图案例核心）。        |
| **复合形状**     | 按住 `Alt` 点击布尔按钮      | 创建**可编辑**的布尔运算结果，随时调整原始形状，非破坏性编辑。 |
| **形状生成器-合并** | 鼠标拖拽划线               | 将划过的所有重叠区域合并为一个形状。                |
| **形状生成器-删除** | 按住 `Alt` + 点击/拖拽     | 删除指定的区域（光标变减号）。                   |
| **多边形边数调整**  | 拖拽时按 `↑` / `↓`       | 增加或减少多边形的边数（如调整为八边形）。             |
| **绘制正圆/正形**  | 按住 `Shift` 拖拽        | 保持长宽比约束。                          |
| **平滑工具保真度**  | 双击工具图标               | 数值越低越平滑，数值越高越接近手绘原迹。              |

### 🚨 避坑指南 (Don't Do This)

- **不要只依赖 `Ctrl+Z`**：传统的布尔运算是一次性的，做错了只能撤销。建议养成使用**复合形状（按Alt）**的习惯，保留修改空间。
    
- **不要忽视“无用”路径**：使用形状生成器或布尔运算后，图层面板里常会残留看不见的废弃路径（如幽灵线），记得及时点击垃圾桶清理，保持文件整洁。
    
- **不要死磕钢笔工具**：遇到标准圆弧或平滑曲线（如鲸鱼的背部），优先用**圆形拟合**（用大圆贴合曲线），而不是手调钢笔锚点，那样更精准且平滑。
    

## 📺 视频全案复盘 (沉浸式学习)

### 📍 01:13 基础工具大起底：画笔 vs 斑点画笔

- **核心概念**：虽然都能画线，但属性截然不同。
    
    - **画笔工具**：画出来的是**路径**（只有描边，无填充）。改色要改描边色。
        
    - **斑点画笔**：画出来的是**形状**（只有填充，无描边）。改色要改填充色，常用于画色块。
        
- _老师说_：“万变不离路径。AI中所有视觉变化本质都是对路径的修改。”
    

### 📍 08:53 拯救手残神器：Shaper工具

- **核心概念**：草图自动规整化。
    
- **操作步骤**：
    
    1. 选中 **Shaper工具**（铅笔工具组内）。
        
    2. 在画板上随手画一个歪歪扭扭的圆或六边形。
        
    3. 松手瞬间，软件会自动识别并将其转换为完美的几何图形。
        
- _老师说_：“你可以把它视作是一个帮助你画标准形状的工具，只要你的草图吻合特征，它就生成你想要的。”
    

### 📍 12:42 布尔运算的核心：路径查找器

- **核心概念**：图形的加减法（并集、交集、差集）。
    
- **功能速览**：
    
    - **联集**：合二为一。
        
    - **减去顶层**：下层减上层（像用模具切饼干）。
        
    - **分割**：极其实用！将所有重叠路径按交点切割成独立小块（后续需进入隔离模式编辑）。
        
    - **轮廓**：仅保留边缘，用于分析结构。
        

### 📍 20:23 实操案例一：太极八卦图绘制

- **核心概念**：利用“分割”和“原位粘贴”快速构建对称图形。
    
- **操作步骤**：
    
    1. **画基座**：画一个大圆（白填充黑描边）。
        
    2. **定圆心**：`Ctrl+C` 复制，`Ctrl+Shift+V` 原位粘贴，缩小至半径一半（构成阴阳鱼头部）。再复制翻转一个。
        
    3. **切分**：画一条穿过圆心的竖线，全选所有图形，点击路径查找器的**“分割”**。
        
    4. **合并**：双击进入编组，将左半边和大圆左下部分**“联集”**，右半边同理，形成蝌蚪状。
        
    5. **上色**：填充黑白，去除不必要的描边。
        

### 📍 25:42 进阶技巧：复合形状 (可编辑的布尔运算)

- **核心概念**：给自己留“后悔药”。
    
- **操作步骤**：
    
    1. 选中要运算的图形。
        
    2. **按住 `Alt` 键**的同时，点击“联集”或“减去顶层”。
        
    3. 结果看似一样，但你依然可以用白箭头独立移动、缩放原始图形，运算结果会实时更新。
        
- _老师说_：“想来就来，想走就走。这解决了布尔运算是一次性操作的痛点。”
    

### 📍 28:25 效率之王：形状生成器

- **核心概念**：直观的“涂抹式”布尔运算，无需思考复杂的上下层关系。
    
- **操作步骤**：
    
    1. **全选**所有重叠的图形。
        
    2. **合并**：直接用鼠标划过想要连在一起的区域，松手即合并。
        
    3. **删除**：按住 **`Alt`** 键（光标变减号），点击或划过不需要的区域（如多余的边角）。
        
- _老师说_：“相当于自动执行‘分割 + 手动选择 + 联集’的一体化操作。”
    

### 📍 32:53 实操案例二：鲸鱼插画 (圆弧拟合)

- **核心概念**：用圆去切出完美的流线型。
    
- **操作指南**：
    
    1. **观察分解**：将鲸鱼的身体曲线拆解为几段圆弧。
        
    2. **圆弧拟合**：
        
        - 画一个圆，使其与目标曲线在某一点**相切**。
            
        - 拉动圆的大小，直到圆弧与参考图的线条完美贴合。
            
        - **注意**：越平缓的线，需要的圆越大；越弯的线，圆越小。
            
    3. **清理多余**：全选所有圆，使用**形状生成器** + `Alt`，删掉鲸鱼身体外部的乱线。
        
    4. **整合细节**：合并内部碎块，对于尖角处，可用**平滑工具**稍微修饰，使其圆润。
        
    5. **渐变上色**：使用“编辑渐变”工具，拉出光影层次。
