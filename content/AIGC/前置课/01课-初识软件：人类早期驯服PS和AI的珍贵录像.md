## 一、 第一步：如何正确地“铺纸” (新建文档)

做设计的第一步不是画画，而是告诉电脑我们要一张什么样的“纸”。

### 1. 核心参数避坑指南 (必背!)

打开 PS 点击左侧【新建】，面对几十个参数，你只需要关注这 3 个：

|   |   |   |   |
|---|---|---|---|
|**你的设计用途**|**单位 (Unit)**|**分辨率 (Resolution)**|**颜色模式 (Color)**|
|**手机/电脑看** (网页、视频、UI)|**像素 (Pixels)**|**72** ppi|**RGB** (光色)|
|**打印出来看** (海报、名片、书籍)|**厘米/毫米**|**300** ppi|**CMYK** (油墨色)|

> 🚨 **新手高频误区**：
> 
> - 千万不要选“位图”或“灰度”，否则你的世界只有黑白！
>     
> - 只要是发朋友圈、做 B 站封面，**一定要选 72 分辨率 + RGB**，文件小且颜色准。
>     

## 二、 界面乱了怎么办？(界面解剖学)

很多新手最怕的就是：“老师，我的工具栏不见了！”

其实 PS 界面只有三个部分是雷打不动的：

### 1. 界面复位大法

不管界面乱成什么样，点击右上角 [工作区图标] -> 选择 [基本功能] -> 点击 [复位基本功能]。

一键回到出厂设置，强迫症福音！

### 2. 三大核心区域

1. **菜单栏 (顶楼)**：功能总目录（文件、滤镜...），知道在哪就行，不用死记。
    
2. **选项栏 (二楼)**：**随工具变化的控制台**。选画笔时它显示大小，选移动工具时它显示对齐。
    
3. **工具栏 (左侧)**：你的百宝箱。
    
    - 🔍 **找不到工具？** 只要图标右下角有**小三角**，**长按左键**就能看到隐藏的兄弟工具！
        

## 三、 核心操作逻辑：编辑 vs 创造

### 1. 怎么把图片放进去？

动作：直接从文件夹拖拽进画布。

关键：看到蓝框白点（变换控件）时，可以缩放旋转。

- ❌ **错误**：拖进去直接点其他工具。
    
- ✅ **正确**：必须按 **Enter 回车** 确认置入，才能进行下一步！
    

### 2. 怎么打字？

动作：按 T 键 -> 点击画布 -> 输入。

逻辑：文字和图片是分层的。想移动文字，必须先在右下角【图层面板】选中文字层。

## 四、 存档的艺术：别让心血白费

做完图怎么保存？PS 提供了三种逻辑，选错可能就白干了。

- 💾 **Ctrl + S (存储)**：
    
    - **作用**：覆盖存档。
        
    - **场景**：做了一半，怕停电，赶紧存一下。
        
- 📂 **Shift + Ctrl + S (存储为)**：
    
    - **作用**：另存新版 (如 `海报_v2.psd`)。
        
    - **场景**：甲方说“还是第一版好”，幸好你存了 v2，v1 还在。
        
- 📤 **Alt + Ctrl + S (存储副本) —— ⭐ 最常用**
    
    - **作用**：导出 JPG/PNG 图片。
        
    - **场景**：做完了，要发给老板或发朋友圈看。**只有用这个功能才能把图层压扁成一张图片！**
