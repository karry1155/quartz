# 🚀 从PS到AI：零基础解锁矢量绘图与图标设计

> 前言：
> 
> 习惯了PS的像素世界，初入AI（Illustrator）可能会感到“水土不服”：为什么没有选区？为什么图层像个大文件夹？但这正是AI的强大之处。本课作为双修课程的AI入门篇，将带你从零建立矢量思维，彻底解决图形放大模糊的痛点，并教你通过一套“一键三连”图标，掌握路径编辑、编组隔离与高效导出的核心技能。

### 🔑 关键操作与快捷键表

| **功能/工具**        | **快捷键/操作**               | **核心作用**                                     |
| ---------------- | ------------------------ | -------------------------------------------- |
| **选择工具 (黑箭头)**   | `V`                      | 移动整体对象、缩放、旋转                                 |
| **直接选择工具 (白箭头)** | `A`                      | **编辑路径形态**、调整单个锚点、拉圆角                        |
| **吸管工具 (高级)**    | `I`                      | 默认吸取所有外观；**按 `Shift` + 点击** 仅吸取当前激活属性（填充或描边） |
| **编组**           | `Ctrl + G`               | 将多个对象打包，防止散乱                                 |
| **进入隔离模式**       | 双击对象/编组                  | 像“关小黑屋”一样专注编辑当前组，不受外部干扰                      |
| **互换填色/描边**      | `Shift + X`              | 快速交换填充色与描边色                                  |
| **原位复制**         | `Ctrl + C` -> `Ctrl + F` | (进阶) 在原位置上方粘贴                                |

### 🚨 避坑指南 (Don't Do This)

- **不要忘记嵌入图片**：置入的JPG/PNG图片如果是“链接”状态，源文件移动后会丢失。**一定要点击“嵌入”**。
    
- **不要对复杂编组直接加描边**：如果你直接给一个包含线条和色块的编组加描边，内部的线条（如“币”字）可能会被覆盖或消失。**正确做法是进入隔离模式单独加，或使用外观面板（进阶）。**
    
- **不要混淆画板与画布**：导出图片时，如果不勾选**“使用画板”**，AI会把画板外所有乱七八糟的草稿全导出来。
    
- **不要用像素思维看图层**：AI的图层更像是一个逻辑文件夹，大多数时候我们直接在画布上点击对象即可，不需要频繁去图层面板找图层。
    

## 📺 视频全案复盘 (沉浸式学习)

### 📍 01:37 新建文档与画板逻辑

- **核心概念**：**画板 (Artboard)**。
    
    - AI的“画板”类似于PS的画布，但AI允许在一个文档里有多个画板（适合做多页UI或名片）。
        
- **关键参数**：
    
    - **光栅效果**：屏幕显示选 **72 ppi** 即可（矢量图本身无分辨率，此选项仅影响滤镜效果）。
        
    - **出血**：印刷专用（防止裁切留白），做屏幕设计时设为0。
        

### 📍 03:09 路径的三要素

- **核心概念**：**锚点、路径、手柄**。
    
- _老师说_：“AI里所有能看到的东西，本质上都是由**填充（实心）**和**描边（轮廓）**构成的。”
    
- **操作演示**：
    
    1. **黑箭头 (V)**：负责“拿取”，移动整个方块。
        
    2. **白箭头 (A)**：负责“捏形”，点击边缘的路径，可以看到锚点，拖动锚点即可改变形状（如把矩形拉成梯形）。
        

### 📍 07:05 吸管工具的高级用法

- **痛点解决**：PS的吸管只吸颜色，AI的吸管默认连“描边粗细、字体样式”一起吸。
    
- **操作步骤**：
    
    1. **全套吸取**：直接点击目标对象 = 颜色+描边+样式全复制。
        
    2. **精准吸取**：先激活工具栏里的“填充”或“描边”色块（谁在上面即激活谁），**按住 `Shift` 点击目标**，只吸取颜色，不改变其他属性。
        

### 📍 11:19 编组与隔离模式 (高频使用)

- **核心概念**：**隔离模式 (Isolation Mode)**。
    
- _老师说_：“双击进入隔离模式，就像把周围的人都请出去，只留下你和你要编辑的对象。”
    
- **操作步骤**：
    
    1. **编组**：选中多个零件，`Ctrl + G`。
        
    2. **修改组内元素**：**双击**该编组，此时背景变淡，只能操作组内元素。
        
    3. **退出**：双击空白处或按 `Esc`。
        

### 📍 17:15 实战：绘制“一键三连”图标

#### 1. 收藏图标 (⭐ 星形改造)

- **操作步骤**：
    
    1. 工具栏长按矩形工具 -> 选择 **星形工具**。
        
    2. 绘制时按 `Shift` 保证正五角星。
        
    3. 切换 **白箭头 (A)**，选中星星上的任意**圆角控制点 (小圆点)**，向内拖动，瞬间变圆润风格。
        

#### 2. 投币图标 (⚪ 形状组合)

- **操作步骤**：
    
    1. **外圈**：椭圆工具画圆。
        
    2. **文字“币”**：
        
        - 横线：使用 **直线段工具**，调整描边粗细。
            
        - **圆头端点**：在“描边”面板中，选择中间的“圆头端点”，让线条末端变圆。
            
        - 中间弧线：画一个正圆，用 **白箭头** 选中底部的锚点并 **删除 (Delete)**，得到完美半圆。
            

#### 3. 点赞图标 (👍 钢笔与圆角)

- **核心技巧**：**局部倒角**。
    
- **操作步骤**：
    
    1. **概括形状**：用钢笔或矩形拼凑出大概的手掌轮廓（直角也没关系）。
        
    2. **局部微调**：
        
        - 用 **白箭头** 框选需要变圆的那个角的锚点。
            
        - 拖动出现的圆角控制点，只让那个角变圆。
            
    3. **对齐锚点**：如果线条画歪了，用白箭头框选两个锚点，使用顶部的对齐工具让它们水平/垂直对齐。
        

### 📍 33:27 文件保存与高效导出

- **核心概念**：**资源导出面板 (Asset Export)** —— UI设计师的神器。
    
- **痛点**：以前需要一个个切片导出，现在可以批量。
    
- **操作步骤**：
    
    1. 窗口 -> **资源导出**。
        
    2. 将绘制好的三个图标（必须是编组）直接拖入面板。
        
    3. 在面板中重命名（点赞、投币、收藏）。
        
    4. 下方设置格式（PNG/SVG）和缩放（1x, 2x, 3x），点击导出，自动生成多倍率文件夹。
