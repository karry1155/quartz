## 🛠️ 核心知识速查 (Quick Reference)

### ⚡ 高频快捷键与操作

| **操作**    | **快捷键/方法**                             | **说明**                  |
| --------- | -------------------------------------- | ----------------------- |
| **复制节点组** | `Ctrl` + 鼠标拖拽框选 -> `Ctrl+C` / `Ctrl+V` | 快速复用已搭建好的模块             |
| **节点编组**  | 选中节点 -> `Ctrl + G`                     | 将散乱节点打包，方便移动和管理         |
| **安装节点**  | Manager搜索 "ControlNet Aux" / "RG"      | 认准 `Aux` 后缀的预处理器插件      |
| **共享模型**  | 修改 `extra_model_paths.yaml`            | 让ComfyUI直接读取WebUI模型，省硬盘 |

### ⚙️ 核心参数避坑指南

- **模型匹配原则**：`SD 1.5` 大模型 **必须搭配** `SD 1.5` 版本的 ControlNet 模型（如 `sd15_openpose_fp16`）。**严禁与SDXL模型混用**，否则生成的图全是噪点。
    
- **Deep Anything V2**：下载内置模型时，推荐选择 **VIT-L** 或 **VIT-B**。_注意：VIT-G通常不可用，请勿选择。_
    
- **网络环境**：首次运行预处理器（如OpenPose、DeepAnything）时会自动下载模型，**必须开启魔法工具**，否则后台会报错失败。

## 📼 视频全案复盘 (Video Full Case Review)

### 📍 02:29 ControlNet 节点安装

- **Manager安装法**：打开管理器 -> 搜索 `internet` 或 `ControlNet` -> 找到带 `Aux` 后缀的 **ControlNet Preprocessors** 点击安装。同时安装 **Advanced ControlNet**。
    
- **Git安装法**：在 `ComfyUI/custom_nodes` 目录下打开CMD，输入 `git clone [仓库地址]`。
    
- **⚠️ 关键点**：安装完成后必须**重启 ComfyUI** 甚至刷新页面才能生效。
    

### 📍 08:33 模型路径共享（省空间必做）

- 在 ComfyUI 根目录找到 `extra_model_paths.yaml.example`。
    
- 用记事本打开，将 `base_path:` 修改为你本地 WebUI 的根目录。
    
- **修改文件名**：去掉 `.example` 后缀，保存为 `extra_model_paths.yaml`。
    
- **效果**：ComfyUI 可直接读取 WebUI 的 Checkpoints 和 VAE，无需重复下载。
    

### 📍 09:47 OpenPose 姿态控制搭建

1. **加载节点**：拖入 `Apply Advanced ControlNet`、`ControlNet Loader`、`Load Image`、`OpenPose Preprocessor`。
    
2. **核心连线**：
    
    - 图像 -> 预处理器 -> Apply节点的图像输入。
        
    - Loader -> Apply节点的模型输入。
        
    - **串联逻辑**：提示词（Positive/Negative）先连入 Apply 节点，再从 Apply 输出连入 KSampler。
        
3. **参数调整**：权重（Strength）控制模仿力度，一般默认 **1.0**。
    

### 📍 18:52 多重控制：串联 Depth 深度节点

1. **复制模块**：按住 `Ctrl` 框选 OpenPose 组，`Ctrl+C/V` 复制一份。
    
2. **替换核心**：
    
    - 将预处理器替换为 **Deep Anything V2**。
        
    - 将 Loader 模型替换为 `sd15_depth_fp16`。
        
3. **串联逻辑（重点）**：
    
    - **OpenPose 的输出**（Positive/Negative） -> 连接到 **Depth 的输入**。
        
    - **Depth 的输出** -> 连接到 **KSampler**。
        
    - _原理：控制条件像接力棒一样层层传递。_
        

### 📍 25:39 风格迁移与画质提升

- **切模型**：将大模型更换为写实类（如 `麦橘写实`），ControlNet 模型保持 1.5 版本不变。
    
- **加 VAE**：为了修补人脸灰暗问题，串联一个 `VAE Loader`（推荐 840000 ），连接到 `VAE Decode`。
    

### 📍 28:09 RG 节点组高效管理

- **安装插件**：在 Manager 中搜索 `RG` (RGThree)，安装并重启。
    
- **功能开启**：右键 RG 节点或在设置中开启 "Group Muting"（分组静音）快捷开关。
    
- **实战应用**：
    
    - 给节点组命名（如“OpenPose组”、“Depth组”）。
        
    - 节点组左上角会出现**开关按钮**，点击即可一键 **Bypass（跳过）** 或 **Disable（禁用）** 该组。
        
    - **忽略多框节点 (Reroute/Fast Groups)**：创建一个总控面板，通过点击按钮一键开关特定 ControlNet 模块，实现“只用姿态”或“姿态+深度”的快速切换。
        

## 🖐️ 关键实操步骤 (Key Practical Steps)

### 实战一：ControlNet "串糖葫芦" 连线法

在 ComfyUI 中使用多个 ControlNet 时，不能并联，必须**串联**。

1. **源头**：大模型加载出的 CLIP Text Encode（正/负提示词）。
    
2. **第一站**：连入 **OpenPose** 的 `Apply ControlNet` 输入端。
    
3. **第二站**：从 **OpenPose** 的输出端，连入 **Depth** 的 `Apply ControlNet` 输入端。
    
4. **终点**：从 **Depth** 的输出端，连入 **KSampler** 的 `Positive/Negative` 输入端。
    

> _💡 提示：如果断开中间任何一环，控制效果就会丢失。_

### 实战二：RG 节点组一键管理

当节点过多时，画布会非常乱，RG 插件能帮你“收纳”。

1. 选中一套功能节点（如 OpenPose 相关的所有节点），按下 `Ctrl + G`。
    
2. 右键点击底部的色块区域，重命名为“OpenPose Control”。
    
3. 利用 RG 插件特性，点击组左上角的 **"Eye" (眼睛)** 图标，即可临时关闭该控制层，方便对比“有/无控制”的效果。
