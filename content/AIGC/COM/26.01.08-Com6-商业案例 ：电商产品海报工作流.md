# 🛍️ ComfyUI 实战：打造电商产品海报生成工作流

> **前言**：本课程深入讲解了如何使用 ComfyUI 搭建两套核心工作流：一是基于 SDXL + BrushNet 的产品换背景工作流，通过语义分割与局部重绘实现高保真产品海报制作；二是基于 Flux.1 Kontext dev 的双图融合工作流，利用大模型强大的理解力实现“一句话改图”。无论你是电商设计新手还是进阶玩家，这套SOP都能助你大幅提升产出效率。

### ⚠️ 避坑指南 & 常见报错

> **BrushNet 节点红框报错解决方法**
> 
> - **现象**：节点无法加载，显示红色边框。
>     
> - **原因**：环境包依赖缺失或版本不匹配。
>     
> - **解决方案**：
>     
>     1. 进入 ComfyUI 根目录：`ComfyUI\python_embeded\Lib\site-packages`
>         
>     2. 在地址栏输入 `CMD` 打开终端。
>         
>     3. 执行命令：`pip install peft==0.14.0` (或 ≥0.7.0 版本)
>         
>     4. 重启 ComfyUI。
>         

### 🧠 核心参数公式 (Flux 分辨率调整)

为了保证 Flux 模型输出最佳画质，图像尺寸建议为 **64 的倍数**：

- **数学表达式**：`size = (original_size / 64) * 64` (取整)
    
- **原理**：SD 系列模型训练多基于 64 倍数尺寸 (512, 768, 1024)，符合此规律可减少伪影。

## 🎬 Part 2: 视频全案复盘 (Video Review)

### 📍 00:52 课程概览与核心节点介绍

- **G-Dino SAM**：高精度自动化抠图神器，无需手动涂抹遮罩，能识别 "product" 或 "person"。
    
- **BrushNet**：局部重绘专家，擅长换装、换背景，能保留原始光影细节。
    
- **Context Devil (Kontext dev)**：基于黑森林实验室 Flux.1 的新模型，支持“一句话改图”，一致性极强。
    

### 📍 02:42 G-Dino SAM 语义分割实操

- **连接逻辑**：
    
    - 加载 `SAM Model` 和 `Grounding DINO Model`。
        
    - **提示词**：输入 `product` (或具体物体名称) 指导分割。
        
    - **输出**：得到 `Image` (抠图结果) 和 `Mask` (遮罩)。
        
- **💡 助教提示**：务必连接 `Preview Image` (预览图像) 节点，确认抠图是否准确，否则后续重绘全是错的。
    

### 📍 06:35 BrushNet 节点详解与环境配置

- **核心结构**：左侧连接大模型、VAE、原图、遮罩；右侧连接 `Brush Model` (运算核心)。
    
- **参数设定**：`Scale` (缩放) 类似 ControlNet 权重，默认 1.0，值越大对画面干预越强。
    
- **环境修复**：(参考 Part 1 的避坑指南) 解决 `peft` 依赖报错是成功运行的关键。
    

### 📍 13:19 SDXL 工作流搭建 (BrushNet + 抠图)

1. **基础框架**：在 K采样器前串联 BrushNet 节点。
    
2. **遮罩逻辑 (关键点)**：
    
    - **G-Dino** 输出的是**物体遮罩**。
        
    - **必须添加 `Invert Mask` (遮罩反转)** 节点。
        
    - **原因**：我们要重绘的是**背景**，不是产品！反转后，白色区域变为背景，黑色区域为产品保护区。
        

### 📍 18:09 增强控制：ControlNet 组合拳

为了防止产品形变，引入双重控制：

- **Canny (硬边缘)**：锁死产品轮廓线条。
    
- **Depth (深度)**：控制前后景空间关系，**权重建议降低至 0.3**，让融合更柔和。
    

### 📍 28:07 进阶技巧：混合局部重绘 (Mixed Inpainting)

- **痛点**：直接生成的图片，产品边缘可能生硬或光影不自然。
    
- **解决方案**：
    
    - 引入 `Mixed Inpainting` 节点。
        
    - 输入 1：原始高清产品图。
        
    - 输入 2：VAE 解码后的生成图 (带背景)。
        
    - **效果**：将原图无缝“贴”回生成背景中，瓶身光泽、边缘过渡瞬间自然，**还原度提升 200%**。
        

### 📍 38:04 Flux.1 Context 双图融合工作流

- **模型三件套**：`UNET (Flux dev fp8)` + `Dual CLIP (t5xxl + clip_l)` + `VAE (ae.sft)`.
    
- **双图拼接逻辑**：
    
    1. 上传两张图 (如：产品图 + 参考背景图)。
        
    2. 使用 `Image Concat` 左右拼接。
        
    3. 使用 `Image Resize` 缩放至合理尺寸 (防爆显存)。
        
    4. **VAE Encode** 进入潜空间。
        
- **生成奥义**：无需复杂的 ControlNet，仅靠 Flux 强大的语义理解。提示词示例：“make two dolls hug each other, keep background style unchanged”。
    

## 🔧 Part 3: 关键实操步骤 (Actionable Steps)

### 场景一：SDXL 产品换背景 (高还原度)

1. **抠图准备**：加载图像 -> 连接 `G-Dino SAM` -> 输入提示词 `product` -> **预览确认**。
    
2. **遮罩处理**：将 Mask 输出连接至 `Mask Invert` (反转) -> 连接至 BrushNet 的 `Mask` 输入。
    
3. **BrushNet 接入**：模型/VAE/图像/反转遮罩 -> 连接 BrushNet -> 输出至 K采样器。
    
4. **光影融合**：生成图 + 原图 -> `Mixed Inpainting` -> 最终输出。
    

### 场景二：Flux Context 双图融合 (创意合成)

1. **双图输入**：加载图 A (主体) + 图 B (风格/背景)。
    
2. **预处理**：`Image Batch` 或 `Image Concat` 拼接图像 -> `Image Scale` (缩放至 1024 左右)。
    
3. **尺寸修正 (防报错)**：
    
    - 添加 4 个 `Math Expression` 节点。
        
    - 公式：`a = (Width / 64) * 64`。
        
    - 将计算后的 W/H 传给 `Flux Resolution` 节点。
        
4. **提示词引导**：在 CLIP 文本编码器中输入自然语言指令 (如“融合图片，保持左图物体，应用右图背景”)。
