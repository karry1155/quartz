# 👗 电商模特换装工作流：Flash Fill + ACE++ 实战指南

> **前言**：欢迎来到本期课程！上节课我们掌握了更换产品背景的技巧，今天我们将进阶挑战——电商模特换装。本课核心在于利用 Flash Fill、Flash Reduce 与阿里 ACE++ 模型，实现“指哪换哪”：保留模特的姿态与背景，精准替换衣服、鞋帽。告别手动涂抹遮罩，让我们开启高效自动化的 AI 换装之旅！

## 📊 核心知识速查 (Quick Reference)

### 🛠️ 必备模型与插件配置

| **组件类型** | **名称/关键词**                   | **安装路径/说明**                                       |
| -------- | ---------------------------- | ------------------------------------------------- |
| **核心模型** | `Flux Fill` (FP8 或 GGUF)     | `ComfyUI\models\unet`<br>_注：8G显存选GGUF版，12G+选FP8版_ |
| **风格模型** | `Flux Redux`                 | `ComfyUI\models\style_models`                     |
| **视觉模型** | `Sigclip Vision Patch14 384` | `ComfyUI\models\clip_vision`                      |
| **辅助模型** | `ACE++ LoRA`                 | `ComfyUI\models\loras`                            |
| **分割模型** | `Segformer` (B3版)            | `ComfyUI\models` (需在节点管理器安装对应节点)                  |
| **插件节点** | `ComfyUI Segformer`          | 管理器搜 "seg former" (绿色图标)                          |
| **插件节点** | `GGUF`                       | 管理器搜 "GGUF" (低显存必装)                               |

### 💡 避坑指南 & 关键参数

- **显存要求**：最低 **8GB**，推荐 **12GB+**。显存不足请务必使用 **GGUF** 版本模型。
    
- **Flash 引导值**：在换装流程中，需将默认的 `3.5` 大幅提升至 **30**，以增强控制力。
    
- **提示词策略**：本工作流主要依赖图像特征，**文本编码器（Positive/Negative Prompt）通常留空**。
    
- **图片拼接原则**：`1对1`（图像对图像），`2对2`（遮罩对遮罩），顺序不可乱。
    

> 🧠 **思维导图占位符**：此处建议绘制 "原图 -> Segformer分割 -> 图像/遮罩拼接 -> Redux/ACE++ 特征注入 -> K采样器 -> 裁剪输出" 的流程图。

## 🎞️ 视频全案复盘 (Timeline Review)

### 📍 00:07 课程目标与核心逻辑

- **目标**：更换模特身上的指定服饰（衣、鞋、帽），同时**绝对锁定**模特的脸部特征、身体姿态及背景环境。
    
- **核心优势**：引入 **自动化分割**，只需在节点勾选部位（如 `dress`、`hat`），无需人工手绘遮罩，效率倍增。
    

### 📍 01:51 核心模型解析

本工作流的“三驾马车”：

1. **Flash Fill**：负责局部重绘与扩图，理解遮罩区域。
    
2. **Flash Reduce**：负责风格迁移与特征重绘，类似 ControlNet 的功能。
    
3. **ACE++**（阿里通义实验室）：提供**上下文感知**填充，辅助 Flash 模型理解原图结构，提升生成质量。
    

### 📍 06:30 环境配置与节点安装

- **基础环境**：确保 ComfyUI 版本 $\ge$ 0.3.40。
    
- **关键节点**：
    
    - **Segformer**：搜索 `seg former` 安装（认准绿色图标），用于自动抠图。
        
    - **GGUF**：低显存用户必装，用于加载量化模型。
        
- **模型部署**：
    
    - `FP8版本` (~11GB)：性能强，需 12GB+ 显存。
        
    - `GGUF版本` (~6GB)：适合 8-12GB 显存，流畅度高。
        

### 📍 09:57 详解 Segformer 服装分割

- **功能**：比 Segment Anything (SAM) 更懂衣服。能自动识别 `Upper-clothes` (上装)、`Dress` (连衣裙)、`Hat` (帽子) 等。
    
- **参数设置**：
    
    - **模型选择**：推荐 `B3` 版本 (精度更高)。
        
    - **细节处理**：`VIT Matte` 设为 **Local** (本地加载)，提高边缘捕捉精度。
        
    - **遮罩微调**：
        
        - `Erosion` (消融)：向内收缩遮罩。
            
        - `Dilation` (膨胀)：向外扩张遮罩（建议适度开启，增加融合度）。
            

### 📍 17:05 基础工作流搭建 (Flux Base)

1. **加载器**：搭建标准的 Flux 工作流（Union加载器/双Clip/VAE）。
    
2. **Flash 引导**：在正向提示词连线中加入 `Flash Guidance`。
    
    - _注意_：常规生图默认 `3.5`，但换装任务后续需调整。
        
3. **Latent**：控制生成尺寸，本流程中部分 Latent 连接会被切断，由后续 Redux 接管。
    

### 📍 21:43 进阶：引入 ACE++ 与 Redux

1. **ACE++ LoRA**：加载 LoRA 并连接 `Differential Diffusion` (差异扩散) 节点，最终接入 K 采样器。
    
2. **Redux Advanced**：
    
    - **连接逻辑**：接收正向/负向条件，输出给 K 采样器。
        
    - **模型加载**：连接 `Flux Redux` 风格模型 + `Sigclip Vision 384` 视觉模型。
        
    - **输入源**：需同时接收 **图像** (Image) 和 **内部模型条件**。
        

### 📍 26:46 图像预处理与拼接 (关键逻辑)

这是换装成功的物理基础：

1. **输入源**：准备两张图 —— **模特原图** + **产品图**（平铺/挂拍）。
    
2. **Clip 视觉编码**：将产品图特征输入给 Clip Vision，让 AI "看懂" 衣服。
    
3. **自动抠图**：模特图接入 `Segformer`，选择对应部位（如连衣裙）。
    
4. **尺寸统一**：使用 `按宽高比例缩放` 节点，确保模特图与产品图尺寸（或长边）一致，避免拼接变形。
    
5. **拼接魔法**：
    
    - **图像拼接**：使用 `空图像` 节点作为底板，将 `模特图` 和 `产品图` 拼在一起。
        
    - **遮罩拼接**：将 `模特遮罩` 转为图像 -> 拼接 -> 转回遮罩。
        
    - _目的_：告诉 AI，“把右边产品的特征，画到左边模特的遮罩区域里”。
        

### 📍 34:59 参数修正与最终生成

- **引导值暴改**：将 Flash Guidance 从 `3.5` 改为 **30**。
    
    - _原理_：高引导值强迫模型严格遵循 Reference 图像（产品图）的特征，否则衣服会“乱变”。
        
- **Prompt 留空**：文本编码器不输入任何词，全靠图像驱动。
    
- **裁切输出**：生成的是拼接图（左模特+右产品），需使用 `Image Crop` 节点，利用原图尺寸信息，自动把左侧模特裁切出来作为最终成品。
    

### 📍 48:03 特殊情况：帽子抠图翻车怎么办？

- **问题**：Segformer 对某些复杂帽子（如大沿帽）顶部识别不全。
    
- **Plan B**：回退使用 **Segment Anything Ultra V2 (SAM)**。
    
    - 虽然 SAM 需要手动提示或更复杂的设置，但在特定边缘识别上可能优于 Segformer。
        

## 🔧 关键实操步骤 (Actionable Steps)

1. **环境自检**：
    
    - 确认 ComfyUI 版本，根据显存下载 FP8 或 GGUF 版本的 Flux Fill 模型。
        
    - 下载 `Segformer` B3 模型至 `models` 文件夹。
        
2. **搭建分割模块**：
    
    - 加载模特图 -> `Segformer Ultra V2`。
        
    - 选择类别（如 `Dress`）。
        
    - 设置 `VIT Matte` 为 Local，最大尺寸 `2.0`。
        
3. **构建拼接链路**：
    
    - **图像路**：`模特图` + `产品图` -> 缩放至同宽/高 -> 拼接到空图像。
        
    - **遮罩路**：`Segformer输出遮罩` -> 转图像 -> 拼接到空遮罩 -> 转回遮罩 -> **遮罩扩展** (Grow Mask, 增加边缘融合)。
        
4. **Redux 核心配置**：
    
    - 加载 `Flux Redux` 和 `ACE++ LoRA`。
        
    - 连接 `Redux Advanced` 节点。
        
    - **关键操作**：将拼接后的图像和遮罩输入给 Redux。
        
5. **参数核对 (Checklist)**：
    
    - [ ] Flash Guidance = **30** (非3.5)。
        
    - [ ] 文本提示词 = **空**。
        
    - [ ] K采样器步数 = **20-30** (视细节需求调整)。
        
    - [ ] CFG = **4.0 - 8.0**。
