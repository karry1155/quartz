## 🎞️ 视频全案复盘 (Step-by-Step Guide)

### 📍 00:07 部署前的“体检”：判断工作流是否适合你

**不要盲目下载！** 在部署前先进行两轮评估，避免浪费时间。

1. **硬件适配性评估**：
    
    - **显存决定上限**：动画类、视频类工作流通常是“显存杀手”，6GB-8GB 显存用户慎入。
        
    - **关键词识别**：在 Liblib 或其他平台查看工作流标题。
        
        - 含 `Flux`：需要高性能显卡。
            
        - 含 `SD1.5` / `SDXL`：相对亲民。
            
        - 含 `Force 2` / `反推`：通常内置大语言模型，对内存和显存有要求。
            
2. **获取需求信息**：若作者未明示，可直接问 AI 助手或查看评论区反馈。
    

### 📍 05:08 读懂 ComfyUI 的“报错语言”

当工作流拖入界面后，ComfyUI 会用不同颜色的框告诉你缺什么：

- ❌ **粗红色框 (Blocked Red)**：**未安装该节点**。这是最常见的问题。
    
- 🟪 **紫色框 (Purple Box)**：节点已安装，但**节点内部自动下载模型失败**。通常因为网络问题（未开代理）。
    
- ➖ **细红色描边 (Thin Red Line)**：**缺少具体的模型文件**（如大模型、LoRA、ControlNet 模型）。
    

### 📍 06:13 第一步：消灭“粗红框” (安装节点)

1. **一键安装**：点击右侧菜单 `Manager` (管理器) -> `Install Missing Custom Nodes` (安装缺失节点)。
    
2. **关键动作**：**必须开启代理工具**，否则下载极易失败。
    
3. **批量执行**：勾选所有缺失节点，点击 `Install`。
    
4. **重启生效**：安装完成后，**必须重启 ComfyUI** 并刷新浏览器页面。如果红框依旧，说明安装失败（通常是网络问题），需重试。
    
    - _备选方案_：如果管理器无法安装，复制节点名称，去“启动器”的扩展管理中搜索安装，或使用 Git 手动安装。
        

### 📍 11:05 第二步：消灭“细红线” (模型下载)

节点装好了，但加载器还是红线报错？那是缺模型文件。

- **寻找模型线索**：
    
    - 进入 `ComfyUI\custom_nodes\对应节点文件夹`。
        
    - 打开 **`README.md`** 文件（用记事本）。
        
    - 作者通常会明确写出：**需要什么模型** + **放在哪个路径**。
        
- **下载的三种姿势**：
    
    1. **管理器自动下**：在 Manager 中搜索模型名称（如 `IC Light`），点击安装（需代理，速度较慢）。
        
    2. **网页极速下 (推荐)**：去 Hugging Face 搜索模型 ID，直接下载文件。**速度通常快于管理器后台下载**。
        
    3. **网盘搬运**：使用国内网盘链接下载，手动复制到 `README` 指定的目录（如 `models/unit/IC_Light`）。
        
- **路径陷阱**：大模型 (Checkpoint) 即使下载了，如果放在了子文件夹（如 `SD1.5/写实类`），ComfyUI 可能识别不到。
    
    - _解决方法_：在加载器节点手动重新选择路径，或将模型移动到根目录。
        

### 📍 26:12 第三步：终极BOSS (环境依赖配置)

有些节点装好了，模型也下了，但一运行就报错？很可能是 **Python 环境库版本不对**。

1. **诊断**：查看节点文件夹下的 `requirements.txt`，里面写了它依赖的 Python 库版本（如 `transformers==4.50.0`）。
    
2. **检查**：去 `python/lib/site-packages` 看你有没有这个库。
    
3. **手动修复 (高阶必会)**：
    
    - 在 `python` 文件夹路径栏输入 `cmd` 回车。
        
    - **关键操作**：将 `python.exe` 拖入黑色命令行窗口（确保用的是 ComfyUI 自带的 python）。
        
    - 输入命令： `-m pip install transformers==4.50.0` (注意空格)。
        
    - 回车执行，看到 `Successfully installed` 即为成功。
        

### 📍 34:01 进阶：云端发布 (Liblib)

本地跑不动？把工作流上传到 Liblib 云端跑。

1. 点击 Liblib 网页右上角“发布工作流”。
    
2. 填写信息（分类、原创/转载声明）。
    
3. 拖入你的 JSON 工作流文件。
    
4. **自动识别**：平台会自动识别缺失的模型和节点。
    
5. 上传一张效果图做封面，提交审核。
    

## 🔧 关键实操步骤 (Actionable Steps)

遇到任何外部工作流，请严格执行以下 **SOP (标准作业程序)**：

1. **拖入诊断**：将 JSON/图片拖入 ComfyUI，观察红框类型。
    
2. **节点修复**：
    
    - 打开代理 -> Manager -> Install Missing Nodes -> 重启。
        
    - _Check Point:_ 粗红框是否全部消失？
        
3. **模型补全**：
    
    - 查看细红线节点 -> 找到对应 custom_nodes 文件夹 -> 阅读 README。
        
    - 下载模型 (推荐 HF/网盘) -> 放入指定 `models/xxx` 目录 -> 刷新页面。
        
    - _Check Point:_ 细红线是否消失？
        
4. **环境排查** (如果运行报错)：
    
    - 将报错信息发给 AI 助手分析。
        
    - 定位缺失的 Python 库 -> 使用 CMD 手动 pip install 安装。
        
5. **替换微调**：
    
    - 如果缺失特定大模型 (Checkpoint)，可用本地同类型的模型 (如用 v7.0 替代 v6.0) 临时替换测试。
