## 🎞️ 视频全案复盘

### 📍 00:00 课程概览与前置准备

ComfyUI 是一个功能强大的节点式 AI 工作流软件。本节课我们将完成从基础环境（Git, Python, CUDA）到软件本体及插件管理的完整部署。

### 📍 01:48 Git 安装与环境变量配置

Git 是版本控制工具，用于后续下载和更新插件。

1. **下载与安装**：从官网下载，安装全程点击 `Next` 默认安装即可。
    
2. **关键步骤：环境变量**
    
    - 找到安装路径下的 `bin` 文件夹（例：`C:\Program Files\Git\bin`）复制路径。
        
    - **操作**：系统搜索“编辑系统环境变量” -> “环境变量” -> “系统变量” -> `Path` -> “新建” -> 粘贴路径。
        
    - **补充**：同样将 `cmd` 文件夹路径添加进去。
        

### 📍 05:07 Python 环境部署

1. **版本选择**：推荐 **3.10** (稳定) 或 **3.12** (官方推荐)。
    
2. **核心操作**：运行安装包时，**必须勾选底部 `Add Python to PATH`**，然后点击 `Install Now`。
    

### 📍 06:20 显卡驱动与 CUDA 配置

确保 AI 跑图性能的核心。

1. **驱动更新**：去 NVIDIA 官网下载对应显卡型号的 `Game Ready` 驱动并安装。
    
2. **CUDA Toolkit**：
    
    - **检查版本**：`Win+R` -> 输入 `cmd` -> 输入 `nvidia-smi` 查看右上角 CUDA Version。
        
    - **安装**：下载对应版本（如 12.6），按指引默认安装。
        
    - **验证**：CMD 中输入 `nvcc -V` 出现版本号即成功。
        

### 📍 11:35 图片转视频工具 (FFmpeg) & Visual Studio

- **FFmpeg**：解压到**纯英文路径**，将 `bin` 目录路径添加到系统环境变量 `Path` 中。
    
- **Visual Studio**：安装时勾选 **“使用 C++ 的桌面开发”** 及右侧默认勾选的组件，用于编译某些特殊节点。
    

### 📍 15:52 ComfyUI 本体安装与模型共享

1. **安装**：解压安装包至全英文路径。
    
2. **模型共享 (省硬盘神器)**：
    
    - 进入 `ComfyUI` 根目录 -> `example` 文件夹。
        
    - 用记事本打开 `extra_model_paths.yaml.example`。
        
    - **修改**：将 `base_path` 修改为你 WebUI (SD) 的安装路径。
        
    - **生效**：保存文件，并将文件名重命名为 `extra_model_paths.yaml` (删除 `.example`)。
        
    - **重启**：重启 ComfyUI，刷新即可看到 WebUI 中的模型。
        

### 📍 20:59 启动器高级设置

使用启动器（如绘世启动器）能更方便地管理。

- **专家模式**：在设置中开启。
    
- **代理设置 (重要)**：填入本地魔法工具的端口号，并开启下方 4 个开关。这是后续下载插件不报错的关键。
    
- **Python 路径**：将 `ComfyUI\python\python.exe` 的完整路径填入启动器设置中。
    

### 📍 24:28 插件安装的三种姿势

1. **启动器安装**：在“插件/扩展”页面搜索（如 `Manager`），点击安装。
    
2. **URL 安装**：复制插件 GitHub 地址，粘贴到启动器安装栏。
    
3. **Git Clone (硬核)**：
    
    - 进入 `ComfyUI\custom_nodes` 目录。
        
    - CMD 输入：`git clone [GitHub链接]`。
        
4. **解压安装**：下载 ZIP 包解压到 `custom_nodes`，**记得重命名去掉后缀**。
    

### 📍 30:24 节点环境依赖管理 (解决报错核心)

当新装节点报错缺失模块时：

1. 进入该节点文件夹，查看 `requirements.txt`。
    
2. **终极安装法**：
    
    - 在插件根目录打开 CMD。
        
    - 拖入 `ComfyUI` 自带的 `python.exe` 文件。
        
    - 输入命令： `[空格] -m pip install -r requirements.txt`。
        
    - 回车执行，自动补全缺失环境。
        

## 🔧 关键实操步骤

### 实操一：ComfyUI 模型共享配置

> **场景**：不想重复下载几十 G 的大模型，直接调用 WebUI 的模型库。

1. **定位文件**：找到根目录下 `extra_model_paths.yaml.example`。
    
2. **编辑路径**：
    
    ```
    # 示例修改
    base_path: D:\Stable Diffusion\sd-webui  <-- 修改为你的 WebUI 实际路径
    checkpoints: models/Stable-diffusion
    ```
    
3. **重命名**：去掉 `.example` 后缀，变为 `extra_model_paths.yaml`。
    
4. **重启**：重启 ComfyUI 即可生效。
    

### 实操二：手动安装节点依赖环境

> **场景**：安装新节点后 ComfyUI 启动报错，提示 "No module named..."。

1. **进入目录**：打开报错节点的文件夹（在 `custom_nodes` 下）。
    
2. **调用 CMD**：在地址栏输入 `cmd` 回车。
    
3. **执行命令**：
    
    - 先找到 ComfyUI 的 python.exe 路径（例如 `D:\ComfyUI\python\python.exe`）。
        
    - 在 CMD 输入：
        
    
    ```
    "D:\ComfyUI\python\python.exe" -m pip install -r requirements.txt
    ```
    
    - **注意**：如果不确定 python 路径，可以直接把 `python.exe` 文件拖入 cmd 窗口，它会自动填入路径。
        
4. **等待完成**：等待进度条跑完，重启 ComfyUI。
