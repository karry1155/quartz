## 📊 核心知识速查

### ⚡ 快捷键与关键参数

| **类型**  | **内容**          | **说明**                        |
| ------- | --------------- | ----------------------------- |
| **快捷键** | `Ctrl + G`      | 将选中的多个节点编组（Group），方便管理        |
| **参数**  | **Steps: 50**   | 千问Image Editor官方推荐迭代步数        |
| **参数**  | **CFG: 4.0**    | 千问Image Editor官方推荐提示词引导系数     |
| **参数**  | **Shift: 3.0**  | `ModelSamplingAura`节点中的推荐偏移指数 |
| **硬件**  | **RTX 5060 Ti** | 当前高性价比显卡推荐（约3500元）            |
| **硬件**  | **内存 64GB+**    | 若涉及视频生成（图生视频），建议大内存防爆         |

### ⚠️ 避坑指南

- **节点报红**：通常因节点缺失导致，推荐使用管理器（Manager）在线安装；若缺失特殊节点，去Liblib搜节点简介找英文名。
    
- **图像模糊**：不要盲目调大分辨率（如512强拉到1024），应使用**放大工作流**（如CCSR或UltraSharp）。
    
- **显存设置**：高性能显卡建议**关闭**“使用共享显存”，否则会显著拖慢生图速度。
    
- **模型匹配**：大模型、LoRA、Text Encoder必须版本对应（如都用千问系列）。

### 📍 32:44 实操演示：魔搭社区 (ModelScope)

- **新模型亮相**：**通义千问 Image Editor 2511**（具有强语义理解与编辑能力）。
    
- **操作流**：进入AIGC专区 → 专业生图 → 选择模型。
    
- **案例**：输入提示词“一个女孩...背景是圣诞节欢乐氛围”，模型能自动识别语义为人物添加圣诞帽，且保留原图Logo细节。
    
- **LoRA技巧**：魔搭社区分类较乱，建议先在“模型广场”筛选并收藏，生图时通过收藏夹调用。
    

### 📍 51:53 深度解析：Editor模型与硬件

- **Editor特性**：名称带`Editor`的模型（类似即梦4.1、香蕉模型）支持**指令式修图**，可直接输入“把背景改成红色”而非复杂的参数微调。
    
- **硬件真相**：
    
    - **显存**：视频生成起步建议16G显存（如4090）。
        
    - **内存**：32GB内存容易爆，做视频建议上**64GB**。
        
    - **性价比**：RTX 5070Ti以上溢价高，预算有限优先保内存。
        

### 📍 01:08:30 理论内功：节点与模型解构

- **CLIP (Text Encoder)**：翻译官，将人类语言（Prompt）转译为机器向量。
    
- **VAE**：调色师，负责图像解码、色彩还原与细节修复。
    
- **Sampler (采样器)**：建筑师，通过降噪（Denoise）从噪声中“雕刻”出图像。
    
    - `Denoise=1.0`：完全重绘（纯噪声开始）。
        
    - `Denoise<1.0`：基于底图修改（图生图逻辑）。
        

## 🛠️ 关键实操步骤

### 🚀 实战一：搭建千问2509本地工作流 (高阶)

_目标：在ComfyUI中搭建Qwen Image Editor 2509工作流，实现双图融合编辑。_

1. **加载三大件**：
    
    - **大模型**：使用`UNETLoader`加载 `qwen_image_editor_2509.safetensors`。
        
    - **CLIP**：使用`CLIPLoader`加载对应的文本模型。
        
    - **VAE**：使用`VAELoader`加载 `qwen_image_vae`。
        
2. **核心节点配置**：
    
    - 添加 **`TextEncodeQwenImageEditPlus`**：这是关键！它有3个图像输入口（input_1, input_2...），支持多图融合。
        
    - 添加 **`ModelSamplingAura`**：**必须添加**，并将`shift`（偏移指数）设置为 **3**。
        
    - 添加 **`ServiceNormal`**：辅助节点。
        
3. **连接逻辑**：
    
    - `CLIP` 连接至 `TextEncode`。
        
    - `TextEncode` 的正/负条件连接至 `KSampler`。
        
    - `Model` 输出连接至 `ModelSamplingAura` 再连至 `KSampler`。
        
4. **图像融合玩法**：
    
    - 上传“吉他图”至 `input_1`，上传“沙发图”至 `input_2`。
        
    - 输入指令：“将图一的吉他与图二的沙发结合”。
        
    - 运行生成，观察AI如何理解空间关系。
        

### 🔍 实战二：解决节点缺失

1. 查看节点右上角名称，那是**节点组**的名字。
    
2. 在Manager中搜索该组名安装。
    
3. 若找不到：
    
    - 在Liblib搜节点中文名，看简介找英文原名。
        
    - 问AI：“ComfyUI [中文名] 节点的英文是什么？”。
