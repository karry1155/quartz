# 🚀 ComfyUI进阶实战：IP Adapter风格迁移与人脸完美复刻

> **前言**：大家好，我是你们的课程笔记助教。在ComfyUI中，如何像WebUI一样生成高质量图片，并实现完美的人物与背景融合？本节课我们将攻克四大难关：还原WebUI画质、IP Adapter风格迁移、多ControlNet精准控制以及面部细节修复。这套工作流将助你轻松搞定“换背景不换脸”的高阶需求，不仅让画面风格统一，更能保证人物五官的超高还原度！

## ⚡ 核心知识速查 (Cheat Sheet)

| **🔧 核心参数/设置**   | **⚙️ 推荐配置/说明**                                    |
| ---------------- | ------------------------------------------------- |
| **文本编码器 (CLIP)** | 推荐使用 **BNK版本**，权重插值方式必须设为 `A1111`                 |
| **采样器设置**        | **DPM++ 2M SDE** + `Carrots` 调度器 (噪波模式设为 `A1111`) |
| **CLIP 停止层**     | ComfyUI默认设置为 `-2`                                 |
| **IP Adapter模型** | 推荐 `Plus (High Strength)` 高强度版本                   |
| **ControlNet权重** | 建议初始设为 `0.5`，结束时间设为 `0.7` (留给AI发挥空间)              |
| **面部细化模型**       | 检测: `face_yolov8`                                 |

> **💡 避坑指南 & 快捷键**
> 
> - **复制节点**：按住 `Alt` + 拖动节点，或 `Ctrl+C/V`。
>     
> - **快速连线**：按住 `Shift` + 左键点击输出端，可快速替换/移动连线。
>     
> - **低显存优化**：在“获取图像尺寸”前调整缩放系数（如0.5），降低生成分辨率。
>     
> - **LoRA连线顺序**：`大模型` → `CLIP停止层` → `LoRA加载器` → `提示词`。

## 📼 视频全案复盘 (Timeline Review)

### 第一阶段：还原WebUI级画质的基础搭建

**📍 02:07 核心：为什么要模仿A1111模式？**

- **痛点解决**：很多同学反映ComfyUI生图不如WebUI细腻，关键在于算法模式的差异。
    
- **操作要点**：
    
    1. **加载器选择**：文本编码器必须选 `Advanced CLIP Text Encode (BNK)`。
        
    2. **模式切换**：将“权重插值方式”改为 `A1111`。
        
    3. **采样器设置**：在K采样器中，将 `noise_mode` (噪波模式) 同样改为 `A1111`。
        

**📍 08:34 添加CLIP停止层**

- **连线逻辑**：`大模型CLIP` → `设置CLIP最后一层 (值设为-2)` → `正/负向提示词`。
    
- **LoRA的正确插入位置** (09:10)：若使用LoRA，需接在“设置CLIP最后一层”**之后**，再进入提示词节点。
    

### 第二阶段：IP Adapter 风格迁移工作流

**📍 14:34 双图融合逻辑**

- 我们需要两个`加载图像`节点：
    
    - **图A (人物)**：提供主体结构和面部特征。
        
    - **图B (背景)**：提供艺术风格和环境氛围。
        

**📍 15:55 IP Adapter 核心节点配置**

- **节点组合**：`IPAdapter加载器` + `应用IPAdapter`。
    
- **连线**：
    
    - `背景图` 连接至 `应用IPAdapter` 的图像输入端（注意不要连错成人物图）。
        
    - `模型` 选择 `Plus (High Strength)` 以获得更强的风格迁移效果。
        
- **图像预处理** (17:59)：人物图需要经过 `图像缩放` + `获取图像尺寸`，将尺寸信息传给 `空Latent`，确保生成图分辨率与原图比例一致。
    

### 第三阶段：多重ControlNet 精准控制

📍 20:11 引入ControlNet增强控制力

单纯的IP Adapter可能导致人物走形，必须配合ControlNet。

- **模块1：OpenPose (姿态)** - 锁定人物动作。
    
- **模块2：Depth (深度)** - 使用 `deep anything v2`，锁定前后景深关系。
    
- **模块3：Canny (硬边缘)** - 锁定轮廓线条。
    
- **模块4：LineArt (艺术线稿)** - 增强手绘感细节。
    

**📍 29:25 关键参数调优**

- **权重控制**：将所有CN权重设为 **0.5**（避免过度死板）。
    
- **介入时机**：结束时间设为 **0.7**（后30%步数让AI融合风格，避免画面像“拼贴画”）。
    

### 第四阶段：面部细化 (Face Detailer)

📍 31:16 为什么脸还是不像？

即便有了ControlNet，生成的脸往往还是“AI脸”。我们需要Face Detailer进行二次重绘。

**📍 33:11 面部细化节点搭建**

- **核心组件**：
    
    1. `BBox检测器`：模型选 `face`，负责框选脸部。
        
    2. `SAM加载器`：模型选 `vit-b` (速度快) 或 `vit-h` (精度高)，负责精准分割。
        
    3. `面部细化` 节点：接收原始生成图，输出修复后的图。
        
- **重要连线**：
    
    - 原始VAE解码后的图像 → 面部细化 `image` 输入。
        
    - 大模型、VAE、CLIP、提示词 → 全部重新连入面部细化节点（它相当于在脸上单独跑了一次图生图）。
        
- **降噪强度** (01:00:42)：初始0.5效果不明显，建议提升至 **0.8 - 1.0**，强制AI重绘面部细节，实现高度还原。
    

## 🛠️ 关键实操步骤 (Actionable Steps)

### Step 1: 搭建“高画质”基础底座

1. 创建空白工作流。
    
2. 加载大模型 (推荐麦菊写实类) + VAE。
    
3. 添加 `BNK文本编码器`，开启 `A1111` 模式。
    
4. 添加 `CLIP Set Last Layer` (设为-2)。
    
5. 设置K采样器：`DPM++ 2M SDE` + `Carrots`。
    

### Step 2: 接入 IP Adapter 系统

1. 添加 `应用IPAdapter` 和 `IPAdapter模型加载器`。
    
2. 加载 **背景参考图**，连入IP Adapter的图像端。
    
3. 加载 **人物原图**，通过 `获取图像尺寸` 节点控制 `空Latent` 的宽高。
    

### Step 3: 串联 ControlNet 组

1. 复制4组 ControlNet 堆栈（OpenPose, Depth, Canny, LineArt）。
    
2. **关键操作**：每组的 `图像` 输入端都连接 **人物原图**。
    
3. 将各组 ControlNet 串联（上一组输出连下一组输入），最后接入 K采样器。
    
4. 设置权重 0.5，结束时间 0.7。
    

### Step 4: 部署面部修复

1. 在K采样器后添加 `面部细化 (FaceDetailer)` 节点组。
    
2. 加载 `BBox (face)` 和 `SAM` 模型。
    
3. 将K采样器生成的初稿连入细化节点。
    
4. 调节降噪幅度至 1.0，点击运行，见证奇迹。
