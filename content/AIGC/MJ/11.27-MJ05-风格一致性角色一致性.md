## 📊 核心知识速查 (Cheat Sheet)

### 1. 三大核心参数对比表

| **参数 (Parameter)** | **全称**              | **适用版本** | **功能定义**                            | **权重参数与范围**                             | **推荐设置**                                  |
| ------------------ | ------------------- | -------- | ----------------------------------- | --------------------------------------- | ----------------------------------------- |
| **--sref**         | Style Reference     | V6 / V7  | **风格迁移**：复刻参考图的色彩、笔触、光影，不迁移内容。      | `--sw` (0-1000)<br><br>  <br><br>默认 100 | **300-500**<br><br>  <br><br>(太低无效，太高过拟合) |
| **--cref**         | Character Reference | V6       | **角色参考**：主要保留面部、发型、服装（精度约70%）。      | `--cw` (0-100)<br><br>  <br><br>默认 100  | **70-80**<br><br>  <br><br>(避免僵硬)         |
| **--oref**         | Object Reference    | **V7**   | **全能控制**：角色、物体、动物全覆盖（精度90%+），支持大动态。 | `--ow` (0-1000)<br><br>  <br><br>默认 100 | **400-600**<br><br>  <br><br>(真人转绘需200+)  |

### 2. 避坑指南 & 高频技巧

> 💡 **助教提示**：遇到问题先检查这里！

- **风格迁移不生效？** 将 `--sw` 提高至 500+，并裁剪参考图，只保留最核心的风格区域（去除背景干扰）。
    
- **角色面部崩坏？** 确保参考图分辨率不低于 **512x512**，且面部清晰无遮挡。
    
- **边缘生硬/有重影？** 参考图对比度要高，适当降低 `--ow` (如降至200-300)，或在提示词加入环境光描述 (e.g., `soft lighting`)。
    
- **多风格融合？** 支持多张参考图权重分配，语法：`--sref urlA::2 urlB::3`。

### 📍 02:08 理论模块：风格参考 (--sref) 的商业价值

- **痛点解决**：过去依赖文字描述风格（如“梵高风”）非常模糊，`--sref` 直接通过图片“提取基因”，实现视觉美学的精准复现。
    
- **商业场景**：
    
    - **系列化包装**：确保草莓味、葡萄味果汁包装虽内容不同，但设计语言高度统一。
        
    - **艺术风格迁移**：将经典艺术（如梵高、赛博朋克）融合进现代摄影或产品图中。
        

### 📍 08:08 实操演示：多风格融合（赛博朋克 + 水彩）

**目标**：生成一座赛博朋克城市，但要有水彩的晕染质感。

- **操作逻辑**：不仅仅是一张图，而是同时提取两张图的特征，并通过权重控制比例。
    
- **核心语法**：
    
    ```
    /imagine prompt: cyberpunk city --sref [赛博朋克图链接]::3 [水彩图链接]::2 --ar 16:9
    ```
    
    _解析：`::3` 和 `::2` 决定了画面更偏向赛博朋克的光影，但保留水彩的笔触。_
    

### 📍 13:19 理论模块：角色一致性 (--cref vs --oref)

- **V6 的局限 (--cref)**：只能做到“像”，无法处理纹身、雀斑等微观细节，且大动作下易崩坏。
    
- **V7 的革命 (--oref)**：
    
    - **全对象迁移**：不仅是人，猫狗、沙发、汽车都能锁定。
        
    - **高精度**：细节还原度达 **90%以上**，解决转头崩坏问题。
        
    - **3D一致性**：支持大幅度的视角变化（俯视、仰视）和动作变化（跳跃、奔跑）。
        

### 📍 21:33 实操对比：角色跳跃动作

**测试**：让一个“朋克风拳击女孩”做高难度的跳跃动作。

- **V6结果**：服装纹理丢失，手部变形，角色产生割裂感。
    
- **V7结果 (--oref)**：头发丝、衣服材质（格纹外套）、面部特征高度还原，且动作自然流畅。
    
- **结论**：**做角色一致性，首选 V7 的 `--oref`。**
    

### 📍 25:41 综合实操：高端手表的产品全案可视化

这是一个完整的商业工作流，演示了如何用一张产品图生成全套商用素材。

1. **生成基准图**：用提示词生成一张满意的“高端机械表”作为母本。
    
2. **生成特写 (Close-up)**：
    
    - 锁定母本，通过提示词聚焦“表盘指针”或“皮带扣”。
        
    - 参数：`--oref [手表图] --ow 400` (保证细节不丢)。
        
3. **场景融合 (In-context)**：
    
    - 将手表放入“冷调现代空间”、“黑色石材桌面”。
        
    - 参数：`--oref [手表图] --ow 500`。
        
4. **风格迁移 (Stylization)**：
    
    - **高阶玩法**：同时锁定角色（手表）和风格（张大千水彩）。
        
    - 参数：`--oref [手表图] --ow 500 --sref [水彩图] --sw 200`。
        
    - _注意：如果 `--ow` 太低（如50），AI会乱画表盘；如果 `--sw` 太高，水彩会破坏产品结构。需寻找平衡点。_
        

## 🛠️ 关键实操步骤 (Actionable Steps)

### 场景一：如何控制风格融合比例？

当你需要混合两种截然不同的风格（如“科技感”+“手绘感”）时：

1. **准备素材**：一张强风格图A（主基调），一张辅助风格图B（增加质感）。
    
2. **编写提示词**：描述画面主体内容。
    
3. **输入参数**：
    
    ```
    --sref url_A::3 url_B::1 --sw 500
    ```
    
    _(通过调整冒号后的数字，实时预览融合效果，建议主次分明，不要1:1)_
    

### 场景二：电商产品图生成工作流 (V7 Oref)

1. **定产品**：先跑出一张完美的产品图，获取其 URL。
    
2. **写场景**：
    
    - ❌ 错误写法：“把手表放进咖啡馆”（AI会生硬拼贴）。
        
    - ✅ 正确写法：“一款高端手表放置在深色木纹桌面上，旁边有咖啡杯，晨光洒落”（描述整体画面）。
        
3. **加参数**：
    
    - `--oref [产品URL] --ow 500 --v 7`
        
    - _Tip：如果是静物特写，`--ow` 开高（400-800）；如果是人物拿着产品做动作，`--ow` 适当降低（200-400）以适应透视变化。_
