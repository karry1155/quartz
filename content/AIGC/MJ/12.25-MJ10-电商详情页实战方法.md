# 🚀 AI电商详情页全案实战：从七大逻辑到AI工具流

> 前言：
> 
> 详情页不是枯燥的产品说明书，而是说服用户购买的销售剧本。本课以“高端复古家庭音响”为例，拆解了电商详情页的七大核心模块与主流平台规范，并手把手演示了如何通过 MidJourney + Mix Board + 即梦(Jimeng) + Photoshop 的工具组合拳，高效产出电影级质感的详情页。

## ⚡️ 核心知识速查

### 🛠️ 工具与环境配置表

| **工具名称**        | **核心用途**      | **关键注意事项**                    |
| --------------- | ------------- | ----------------------------- |
| **MidJourney**  | 生成产品主图、俯视图    | 需使用英文提示词；保持宽高比 (3:4 或 4:3)    |
| **Mix Board**   | **局部重绘、细节生成** | **⚠️ 必须切换至美国或新加坡节点**；使用谷歌账号登录 |
| **即梦 (Jimeng)** | 生成场景海报、分解图    | 适合处理复杂光影、文字融合及合成商业海报          |
| **Photoshop**   | 最终排版、参数页制作    | 处理文字层级、制作毛玻璃质感背景              |

### ⌨️ PS高频快捷键与参数

- **全选文字/图层**：`Ctrl + A`
    
- **编组**：`Ctrl + G`
    
- **自由变换**：`Ctrl + T`
    
- **复制图层**：`Ctrl + J`
    
- **参数页排版参考**：
    
    - 正文参数字号：约 **35pt**
        
    - 主标题字号：**45-50pt** (字体加粗/Heavy)
        
    - 行距/字间距：设为 **0** (紧凑感)
        
    - 圆角矩形容器：圆角 **65px**
        
    - 毛玻璃高斯模糊：半径 **8.5 - 9.0**
        

### 🛡️ 平台合规避坑指南

- **淘宝/天猫**：严禁使用“最”、“第一”等极限词；促销需标“广告”。
    
- **京东**：必须提供3C认证、检测报告；医疗器械需标“械字号”。
    
- **抖音/小红书**：
    
    - 抖音：前3秒必须有**视觉爆点**留人。
        
    - 小红书：强调**利他性**，需适配竖屏阅读体验。

### 📍 00:36 课程目标与核心逻辑

### 📍 01:32 理论模块：详情页七大核心模块

1. **产品海报（门面）**：核心任务是**3秒吸睛**。
    
    - _公式_：视觉焦点 + 核心主张（主标题直击价值） + 信任符号（销量/认证）。
        
2. **用户痛点**：精准打击。
    
    - _技巧_：场景化描述（如“防晒要不要卸” vs “不需要卸”）；放大问题制造焦虑与共鸣。
        
3. **产品优势**：差异化价值。
    
    - _关键_：**利益转换**（功能→利益），如“4000毫安”转化为“充一次用一月”。
        
4. **产品特点**：技术成分解析。
    
    - 结合专业背书（研发团队、专利）提升权威性。
        
5. **数据证明**：建立信任壁垒。
    
    - 包含：消费者实测、极限测试（100小时无故障）、第三方检测报告、同类对比表。
        
6. **产品细节**：工艺与人性化。
    
    - 展示按键纹理、不伤手设计、礼盒包装等附加值。
        
7. **产品参数**：决策辅助。
    
    - 优先展示尺寸、重量、场景适配（如“能否装下13寸电脑”）。
        

### 📍 06:35 实战启动：前期准备

- **案例背景**：高端复古家用音响，目标25-40岁人群（音质+家居美学）。
    
- **文案生成**：利用LLM（大语言模型）一键生成Slogan、海报文案、数据背书及参数列表。
    

### 📍 07:10 步骤一：MidJourney 生成产品主图

- **操作**：使用豆包生成提示词，翻译后导入MJ。
    
- **提示词要点**：
    
    > "高端复古家用音响，正面视角，黑色金属磨砂，金属旋钮，柔和影棚光，商业广告风格。"
    
- **技巧**：构图设为 **3:4**，选择清晰正向的图片并高清化。
    
- **变体**：生成俯视图（4:3构图），调整权重确保外观一致性。
    

### 📍 11:36 步骤二：Mix Board 细节优化（黑科技）

- **环境要求**：**必须切换美国/新加坡节点**，谷歌账号登录。
    
- **核心功能**：局部重绘与细节生成。
    
    - _指令示例_：“生成图中红框中的产品按键细节”、“去除红框中多余部分”。
        
- **目的**：解决AI生成产品细节（如Logo、文字、接口）乱码或不清晰的问题。
    

### 📍 14:49 步骤三：即梦(Jimeng) 生成场景海报

- **场景设定**：家庭影院/足球赛现场，深蓝色调，史诗级光影。
    
- **海报1（门面）**：体育场夜景背景 + 悬浮音响。
    
    - _文案_：“原音重现，身临其境”。
        
    - _元素_：添加蓝牙5.3、24H续航等Icon。
        
- **海报2（产品分解）**：**"产品优势分解图"**。
    
    - _提示词调整_：描述音响浮起分解，展示低音炮、芯片内部结构。
        
    - _视觉_：高科技3D渲染，配合文案“三分频独立驱动”。
        
- **海报3（沉浸场景）**：**"数据背书图"**。
    
    - _画面_：前景人物欢呼 + 背景巨幕足球赛（虚实结合）。
        
    - _数据排版_：顶部居中展示频响范围、失真度数据；配合“电流纹理”特效文字。
        

### 📍 32:03 步骤四：Photoshop 参数页精修

- **背景制作**：
    
    1. 导入细节图作为底层。
        
    2. 新建图层吸取顶部颜色填充，添加**渐变蒙版**实现自然融合。
        
    3. 顶部向下拉深色渐变，营造层次感。
        
- **文字排版**：
    
    1. 统一参数字号（约35pt），行/字间距设为0。
        
    2. 产品名加粗加大（45-50pt）。
        
- **UI容器设计（毛玻璃效果）**：
    
    1. 绘制圆角矩形（65px），深灰色填充（透明度70%）。
        
    2. **描边**：黑白渐变描边（5px），模拟玻璃反光。
        
    3. **背景模糊**：复制背景层 -> **高斯模糊 (半径8.5-9)** -> 形成毛玻璃质感，不干扰文字阅读。
        

## 🔧 关键实操步骤 (SOP)

1. **文案先行**：用LLM生成全套策划案（Slogan、痛点、参数、背书）。
    
2. **素材制备 (MJ)**：
    
    - 生成主视角图 (3:4) 和 俯视图 (4:3)。
        
    - 使用 `Mix Board` 修复Logo、按键等微小细节，获取高清局部图。
        
3. **场景合成 (Jimeng)**：
    
    - 将MJ生成的主体图作为参考（Image Reference）。
        
    - 结合商业摄影Prompt（如“大师级灯光”、“史诗级画面”）生成带场景的海报底图。
        
    - 制作“爆炸图/分解图”展现内部科技。
        
4. **排版精修 (PS)**：
    
    - 合成产品图与背景。
        
    - 添加UI容器（圆角矩形+描边）。
        
    - 制作毛玻璃效果提升高级感。
        
    - 排版文字参数，注意对齐与层级。
