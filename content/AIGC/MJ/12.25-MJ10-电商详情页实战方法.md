# 🚀 AI电商详情页全案实战：从七大逻辑到AI工具流

> **前言**：详情页不是枯燥的产品说明书，而是说服用户购买的销售剧本。本课以“高端复古家庭音响”为例，拆解了电商详情页的七大核心模块与主流平台规范，并手把手演示了如何通过 MidJourney + Mix Board + 即梦(Jimeng) + Photoshop 的工具组合拳，高效产出电影级质感的详情页。

## ⚡️ 核心知识速查

### 🛠️ 工具与环境配置表

| **工具名称**        | **核心用途**      | **关键注意事项**                    |
| --------------- | ------------- | ----------------------------- |
| **MidJourney**  | 生成产品主图、俯视图    | 需使用英文提示词；保持宽高比 (3:4 或 4:3)    |
| **Mix Board**   | **局部重绘、细节生成** | **⚠️ 必须切换至美国或新加坡节点**；使用谷歌账号登录 |
| **即梦 (Jimeng)** | 生成场景海报、分解图    | 适合处理复杂光影、文字融合及合成商业海报          |
| **Photoshop**   | 最终排版、参数页制作    | 处理文字层级、制作毛玻璃质感背景              |

### ⌨️ PS高频快捷键与参数

- **全选文字/图层**：`Ctrl + A`
    
- **编组**：`Ctrl + G`
    
- **自由变换**：`Ctrl + T`
    
- **复制图层**：`Ctrl + J`
    
- **参数页排版参考**：
    
    - 正文参数字号：约 **35pt**
        
    - 主标题字号：**45-50pt** (字体加粗/Heavy)
        
    - 行距/字间距：设为 **0** (紧凑感)
        
    - 圆角矩形容器：圆角 **65px**
        
    - 毛玻璃高斯模糊：半径 **8.5 - 9.0**

## 🔧 关键实操步骤 (SOP)

1. **文案先行**：用LLM生成全套策划案（Slogan、痛点、参数、背书）。
    
2. **素材制备 (MJ)**：
    
    - 生成主视角图 (3:4) 和 俯视图 (4:3)。
        
    - 使用 `Mix Board` 修复Logo、按键等微小细节，获取高清局部图。
        
3. **场景合成 (Jimeng)**：
    
    - 将MJ生成的主体图作为参考（Image Reference）。
        
    - 结合商业摄影Prompt（如“大师级灯光”、“史诗级画面”）生成带场景的海报底图。
        
    - 制作“爆炸图/分解图”展现内部科技。
        
4. **排版精修 (PS)**：
    
    - 合成产品图与背景。
        
    - 添加UI容器（圆角矩形+描边）。
        
    - 制作毛玻璃效果提升高级感。
        
    - 排版文字参数，注意对齐与层级。
