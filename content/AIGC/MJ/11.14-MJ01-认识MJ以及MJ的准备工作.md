## 📊 核心知识速查 (Cheat Sheet)

### 🛠️ 常用指令与快捷键

|**指令/按钮**|**功能说明**|**备注**|
|---|---|---|
|**/imagine**|**召唤指令**|一切创作的开始，输入 `/imagine` 后接提示词|
|**/settings**|**设置面板**|调整模型版本(V6/V7)、风格化程度、生成速度等|
|**U1 / U2...**|**Upscale (放大)**|选中第几张图进行高清大图生成|
|**V1 / V2...**|**Variation (变化)**|基于第几张图生成4张风格相似但细节不同的新图|
|**🔄**|**Reroll (重做)**|对当前提示词不满意，重新生成一组全新的4张图|

### 🤖 核心模型对比

| **机器人名称**            | **擅长风格**            | **适用场景**       | **类比**  |
| -------------------- | ------------------- | -------------- | ------- |
| **MidJourney Bot**   | 写实、电影感、油画、3D渲染、史诗氛围 | 摄影大片、商业海报、产品图  | 好莱坞摄影师  |
| **Niji Journey Bot** | 二次元、动漫、插画、精致五官      | 动漫角色、漫画场景、Q版头像 | 日本动漫原画师 |

> **💡 避坑指南**：
> 
> - **空格很重要**：在修改提示词或参数时，参数后缀（如 `--ar 16:9`）前必须加**空格**。
>     
> - **混合模式**：想要在局部重绘或变体时修改提示词，必须先在设置中开启 `Remix Mode`。
>

### 📍 00:10 为什么选择 MidJourney？

- **商业价值**：能迅速将创意转化为高质量设计，广泛应用于广告、电商、影视等领域，变现能力极强。
    
- **四大核心优势**：
    
    1. **极致美学**：色彩、构图接近人类艺术家，自带氛围感。
        
    2. **惊人想象力**：突破人类思维壁垒，数十秒提供多个视觉方案。
        
    3. **低门槛**：无需绘画功底，像聊天一样创作。
        
    4. **高效迭代**：快速调整、重绘、提升画质。
        

### 📍 05:11 理论：Discord 与 MidJourney 的关系

- **形象比喻**：
    
    - **Discord** = **微信**（一个巨大的聊天社群平台）。
        
    - **MidJourney** = **小程序**（驻守在群里的AI绘画大师）。
        
- **工作原理**：输入文字 ➡️ AI云端计算 ➡️ 生成独一无二的图像。
    
- **优势**：无需下载安装包，不吃电脑配置（云端算力），手机平板皆可操作。
    

### 📍 07:32 界面介绍与环境搭建

- **Discord界面分区**：
    
    - **左侧**：服务器列表（类似微信通讯录）。
        
    - **中间**：聊天/创作窗口。
        
    - **右侧**：成员列表（在线的Bot和用户）。
        

### 📍 12:00 实操：MJ 与 Niji 的风格差异

在生成第一张图时，选择正确的机器人至关重要：

- 输入 `a cute cat`（一只可爱的小猫）。
    
- **MJ生成的**：毛发毕现，光影真实，像刚拍的照片。
    
- **Niji生成的**：大眼睛，线条柔和，像动漫截图。
    
- **结论**：想做照片/产品用MJ，想做动漫/IP用Niji。
    

### 📍 14:02 进阶操作：生成后的调整

图生成好后，才是创作的开始：

1. **Upscale (高清)**：
    
    - `Subtle`：微调高清（保留原味）。
        
    - `Creative`：创意高清（增加亿点细节）。
        
2. **Vary (变化)**：
    
    - `Vary (Region)` **局部重绘**：涂抹哪里改哪里（如把粉裙子改成蓝裙子）。_注意：需在英文输入法下操作。_
        
3. **Zoom Out (扩图)**：
    
    - `2x / 1.5x`：镜头拉远，自动补全周围环境。
        
    - `Make Square`：把长图或宽图强行补成正方形。
        

### 📍 16:47 Settings 参数详解

输入 `/settings` 调出控制台：

- **Model**：建议使用最新版（V6.1 或 V7），效果最佳。
    
- **Stylize (风格化)**：
    
    - `Low`：忠实于提示词。
        
    - `High/Very High`：AI发挥艺术性，画面更华丽但可能偏离原意。
        
- **Personalization (个性化)**：V7新功能，开启后生成的图更符合你的审美（需在官网训练）。
    
- **Mode (模式)**：
    
    - `Fast`：快速出图（消耗时间额度）。
        
    - `Relax`：慢速出图（会员无限量，需排队）。

## 🛠️ 关键实操步骤 (SOP)

### 第一步：创建专属“绘画工作室” (服务器)

1. 在Discord左侧栏底部点击 **`+` (添加服务器)**。
    
2. 选择 **“亲自创建”** -> **“仅供我和我的朋友使用”**。
    
3. 起个好听的名字（如“MJ炼丹房”），点击创建。
    

### 第二步：邀请“AI大师”入驻

1. 在右上角搜索栏搜索 **"MidJourney Bot"**。
    
2. 点击机器人头像 -> **“添加至服务器”**。
    
3. 选择刚才创建的服务器 -> **“继续”** -> **“授权”** -> 完成人机验证。
    
4. **重复步骤**：搜索 **"Niji Journey"** 并将其也拉入服务器（专门用于画二次元）。
    

### 第三步：生成第一张图

1. 在聊天框输入 `/`，选择 `/imagine`。
    
2. 在 `prompt` 框内输入英文描述，例如：`a cool boy`。
    
3. 按 **Enter** 发送。
    
4. 等待约1分钟，获得4张缩略图。
    

### 第四步：图片微调

1. **选中喜欢的一张**：点击 `U1` (假设喜欢左上角第一张)。
    
2. **局部修改**：大图生成后，点击 `Vary (Region)`，用选框工具涂抹想要修改的区域（如衣服），在弹出的框中修改关键词（如 `blue shirt`），点击箭头提交。
