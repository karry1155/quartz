### 📊 第一部分：核心知识速查 (Cheat Sheet)

这张表汇集了课程中提及的所有关键参数，建议截图保存，作为日常出图的“手边书”。

|**参数类型**|**指令代码**|**取值范围**|**核心作用与应用场景**|
|---|---|---|---|
|**画幅比例**|`--ar`|x:y|**构图关键**。`16:9`(横屏/风景)、`9:16`(手机壁纸)、`3:4`(人像/iPad)、`1:1`(头像)。|
|**图像质量**|`--q`|.25 - 2|**细节密度**。`.25`(抽象/快)、`1`(默认)、`2`(高细节，如建筑/纹理)。|
|**混乱度**|`--c`|0 - 100|**随机性**。`0`(严格遵循提示词)、`100`(AI放飞自我，适合寻找灵感)。|
|**种子值**|`--seed`|[数字]|**一致性**。锁定画面，用于生成系列图或微调同一画面。|
|**停止生成**|`--stop`|10 - 100|**完成度**。`10-70`(草图/磨皮效果)、`100`(完整细节)。|
|**平铺模式**|`--tile`|无|**纹理设计**。生成可无缝拼接的图案，适用于印花、壁纸。|
|**排除元素**|`--no`|[文本]|**负向提示**。如 `--no people` (画面中不要出现人)。|
|**风格化**|`--s`|0 - 1000|**艺术性**。值越高越艺术/抽象，值越低越写实。V7中`>600`会出现动态模糊。|
|**怪诞值**|`--w`|100 - 3000|**非常规美学**。值越高画面越古怪、独特。|
|**风格预设**|`--style`|raw/exp|`raw`(原始感/摄影)、`expressive`(表现力/插画)。_注：V7对应参数为 `--exp`_。|

### 🎬 第二部分：视频全案复盘

![[../../assets/c7d649b0-edd2-11f0-a9b0-197aa45f94ae.jpg]]
#### 📍 01:41 告别单一：常见出图方式

- **纯文本方式**：`/imagine prompt [提示词]`。最基础的操作。
    
- **垫图+文本方式**：`/imagine prompt [图片链接] [空格] [提示词]`。
    
    - **💡 垫图小技巧**：
        
        1. 将参考图直接拖入MJ对话框发送。
            
        2. **右键点击**图片 -> 选择“复制链接”（Copy Link）。
            
        3. 确保链接后缀是图片格式（.jpg/.png），且**链接与提示词之间必须有空格**。
            

#### 📍 03:28 掌控画面：基础必用参数

- **版本控制** (`--v`)：从V5到V7，每一代对光影、皮肤和语义理解都有提升。
    
- **画幅比例** (`--ar`)：
    
    - **3:4 / 2:3**：最适合**人像摄影**，符合经典构图。
        
    - **16:9 / 9:16**：适合**影视宽屏**或**手机全屏壁纸**。
        
- **图像质量** (`--q`)：
    
    - 想要**建筑草图**或**极简风格**？尝试 `--q 0.5`。
        
    - 想要**极致纹理**（如室内软装细节）？尝试 `--q 2`。
        
- **混乱值** (`--c`)：
    
    - 商业单子（如电商图）求稳？用 `--c 0`。
        
    - 艺术创作求灵感？用 `--c 50` 以上，AI会给你惊喜（或惊吓）。
        
- **种子值** (`--seed`)：
    
    - **获取方法**：对生成的图片添加“信封（envelope ✉️）”表情反应，机器人会私信你Seed值。
        
    - **作用**：填入相同的Seed值，可以复刻出构图极其相似的画面，方便微调颜色或主体。
        

#### 📍 11:19 进阶黑科技：特殊功能参数

- **提前终止** (`--stop`)：
    
    - **神技**：设置 `--stop 70` 可以得到类似“磨皮”的效果（因为细节未完全生成），或者生成一种未完成的艺术草图感。
        
- **平铺模式** (`--tile`)：设计印花布料、包装纸的神器。
    
- **负向参数** (`--no`)：比在提示词里写 "without people" 权重更高，直接写 `--no people` 效果立竿见影。
    
- **风格化与V7新特性**：
    
    - V7版本引入了**动态模糊算法**。当 `--s` (stylize) 大于600时，画面会出现类似运动镜头的残影和颗粒感。
        
    - `--style raw` (V6) 或 `--exp` (V7) 可以去除MJ自带的“滤镜味”，让照片更像相机直出。

### ⚡️ 第三部分：关键实操步骤 (Actionable Steps)

这里整理了课程中演示的三个核心案例，你可以直接复制Prompt进行练习。

#### 🎯 案例一：逼真肖像摄影 (The Realistic Portrait)

- **目标**：去除AI感，模拟真实摄影棚人像，追求磨皮质感。
    
- **操作要点**：使用 `Stop` 参数控制细节生成。
    
- **参考指令**：
    

Markdown

```
/imagine prompt: portrait photo of a woman with short hair, studio lighting, 8K --ar 3:4 --v 6 --s 200 --stop 70
```

> **解析**：`--stop 70` 强制AI在70%进度时停止，意外造就了皮肤的光滑磨皮效果。

#### 🎯 案例二：动漫风格手机壁纸 (Anime Wallpaper)

- **目标**：色彩鲜艳、风格突出的二次元壁纸（适配手机/iPad）。
    
- **操作要点**：结合特定画师风格（如大友克洋风格 Toho style）与画幅控制。
    
- **参考指令 (手机版)**：
    

Markdown

```
/imagine prompt: a girl sitting by the window, raining outside, toho style --ar 9:16 --s 200 --v 7
```

> **解析**：`toho style` 赋予画面独特的二次元笔触；`--ar 9:16` 完美适配手机屏幕；V7模型对光影处理更佳。

#### 🎯 案例三：无缝平铺碎花图案 (Seamless Pattern)

- **目标**：生成可无限延伸的印花图案，用于商业设计。
    
- **操作要点**：必须开启 `--tile`，配合低混乱度保证元素均匀。
    
- **参考指令**：
    

Markdown

```
/imagine prompt: a bird on the branch --tile --ar 1:1 --c 5 --q 2
```

> **后续操作**：生成满意图片后，点击下方的 **[Pan ⬅️/➡️]** 箭头进行延展，或使用 **[Zoom Out 2x]** 扩大视野。
