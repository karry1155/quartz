# 🎬 AI产品创意广告片制作全流程：从零打造万元级商单作品

> **前言：** 不同于普通的AI视频，商业广告片的核心在于“产品一致性”与“卖点表达”。课程以一款 100% NFC橙汁 为案例，演示了如何通过TypeNow、可灵、极梦等工具，制作出一条市场报价 5000-10000元 的高质量创意广告。

## ⚡️ 核心知识速查

### 🛠️ 工具箱与核心功能

| **工具**            | **核心用途**       | **关键技巧/优势**                            |
| ----------------- | -------------- | -------------------------------------- |
| **TapNow** (香蕉)   | **产品生图 (主力)**  | 保持产品**高度一致性**，适合生成标准三视图和特定产品场景。        |
| **DeepSeek / 豆包** | **脚本生成**       | 输入产品卖点，输出结构化的JSON分镜脚本。                 |
| **极梦AI (Jimeng)** | **视频/分镜生成**    | 免费生图练手，支持**智能多帧**（连贯动作）。               |
| **可灵AI (Kling)**  | **视频生成 (I2V)** | 生成质量高，支持**首尾帧**功能（实现平滑过渡）。             |
| **SoV2 Pro**      | **高阶视频生成**     | 处理**复杂运镜**（如FPV穿越、环绕、液体流动），积分消耗高但效果顶级。 |
| **剪映**            | **剪辑与音效**      | **卡点剪辑**、倒放功能、添加品牌Slogan。              |

### 💡 商业广告制作金律

1. **视觉锚点 (Visual Anchors)**：
    
    - 先生成一张完美的**关键帧**（如悬浮的橙子），把它作为锚点。
        
    - **向前联想**：它从哪来？（上帝之手扔下、流星坠落）。
        
    - **向后联想**：它去了哪？（碰撞爆汁、切开）。
        
2. **首尾帧大法 (Start-End Frames)**：
    
    - **原理**：上传“开始图”和“结束图”，让AI生成中间过程。
        
    - **应用**：完整的橙子（首帧） -> 被切开流汁的橙子（尾帧） = 丝滑的切开动画。
        
3. **音乐情绪论**：
    
    - 商业广告必须使用**令人兴奋 (Exciting)**、节奏感强的音乐。拒绝平淡、悲伤或紧张的BGM。
        

## 📼 视频全案复盘：NFC橙汁广告

### 📍 Phase 1: 准备与脚本 (The Blueprint)

**Step 1: 获取产品三视图 (The Foundation)**

- **操作**：从官网/电商页获取产品的多角度高清图（正面、侧面、俯视）。
    
- **合成**：使用 **TapNow** 或 **Midjourney**，通过`垫图 (Image Prompt)`生成一张标准化的产品三视图。这是后续所有生成的“脸面”保障。
    

**Step 2: AI生成分镜脚本 (The Script)**

- **工具**：DeepSeek 或 豆包
- **提示词模板**：
```
我是商业视频导演，请帮我写一个 {产品名称} 的创意分镜脚本。
产品类型：NFC橙汁
核心卖点：100%鲜榨、零添加、果肉饱满
风格要求：超现实主义、艺术感、极强视觉冲击力
输出格式：请使用JSON格式输出，包含画面描述、运镜方式、音效。
```

我的第一版分镜提示词
```
产品名称：健茵宝骄阳舒经霜
产品核心特点：中草药配方,缓解及促进康复, 涂抹式
激发购买欲，给人健康的感觉,帮我生成AI广告视频分镜脚本使用JSON格式文本为中文
```
- **策略**：一次生成4个版本，优中选优，或缝合不同脚本的亮点。
### 📍 Phase 2: 关键帧生成 (The Assets)

我们利用 **TypeNow** (追求一致性) 或 **极梦** 生成以下核心画面的**静态图**

| **分镜序号** | **画面描述 (Prompt思路)**                                                      | **创意意图**      |
| -------- | ------------------------------------------------------------------------ | ------------- |
| **镜头 1** | 极度特写镜头：一颗饱满的橙子星球浮现在空中，清晰可见果皮表面的纹理和凝结的露珠。背景明亮色调，梦幻感。                      | 建立视觉锚点，制造悬念。  |
| **镜头 2** | **上帝之手**：一只发光的手/上帝之手拿着橙子（作为镜头1的前帧）。                                      | 交代橙子来源，增加神圣感。 |
| **镜头 3** | **碰撞爆汁**：两颗橙子在空中高速碰撞，炸裂出金色的汁水。                                           | 视觉冲击，展示新鲜度。   |
| **镜头 4** | 俯视视角，大远景：金色的果汁如瀑布般倾泻而下，撞击在晶莹的冰块上，激起细腻的泡沫和飞溅的水花。画面侧重于液体的质感和光泽度，仿佛能闻到橙子的香气 | 质感展示，激发食欲。    |
| **镜头 5** | **微观穿越**：微距镜头进入果汁内部，看到果肉纤维和DNA螺旋。                                        | 科技感，暗示营养成分。   |
| **镜头 6** | **产品亮相**：橙汁瓶身从冰块/水中缓缓升起，置于艺术装置中。                                         | 最终落幅，强化品牌。    |
	
### 📍 Phase 3: 视频生成与动效 (Motion)

**技术难点攻克：**

1. **橙子切开/爆汁效果**：
    
    - **工具**：可灵AI (Kling)
        
    - **方法**：**首尾帧控制**。
        
    - `首帧`：完整的橙子图。
        
    - `尾帧`：切开/爆裂的橙子图。
        
    - `提示词`：`橙子被切开，汁水四溅，高速摄影`。
        
2. **复杂液体流动/FPV运镜**：
    
    - **工具**：SoV2 Pro (积分燃烧者，但在复杂物理模拟上效果最好)
        
    - **场景**：果汁撞击冰块乐园、FPV穿越果汁通道。
        
    - **提示词**：`FPV drone shot, flying through the juice tunnel, cinematic lighting`。
        
3. **产品展示环绕**：
    
    - **工具**：极梦AI 或 可灵
        
    - **方法**：上传产品静帧。
        
    - **提示词**：`环绕运镜 (Orbit camera)，产品保持静止，背景流动`。
        

### 📍 Phase 4: 剪辑与后期 (Editing)

**工具**：剪映 (CapCut)

1. **选曲**：选择一首BPM较高、有明显**鼓点 (Beat)** 的快节奏商业音乐。
    
2. **卡点剪辑**：
    
    - 打开剪映音频轨道的`自动踩点`或手动看波形图。
        
    - **高潮点**：将“橙子碰撞爆汁”或“产品出水”的震撼镜头放在音乐的高潮第一拍。
        
3. **倒放技巧**：
    
    - 生成的视频如果是“拉远”，可以点击`倒放`变成“推进”，增加视觉张力。
        
4. **调色与画质**：
    
    - 如果生成的果汁颜色像“冰红茶”或“油”，需在生图阶段修改提示词（如`bright orange color`），或在剪映中调节`HSL`（色相/饱和度）将黄色/橙色提亮。
        
5. **结尾落幅**：
    
    - 必须定格在产品高清图。
        
    - 添加品牌Logo、Slogan（如“100%纯粹”）和购买引导。
        

## 📝 课后作业

**作业目标**：制作一条 **10秒** 的产品创意广告（练手级）。

**步骤**：

1. 找一个你喜欢的产品（饮料、香水、鞋子均可）。
    
2. 利用 **DeepSeek** 写出3个关键分镜。
    
3. 使用 **极梦AI** (免费生图) 生成这3张关键帧（首中尾）。
    
4. 使用 **极梦** 或 **可灵** 的图生视频功能，让画面动起来。
    
5. 在剪映中配上一段动感的BGM，卡点导出。
