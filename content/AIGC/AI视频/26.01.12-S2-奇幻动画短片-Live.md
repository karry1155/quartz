# 🎬 AI奇幻动作短片制作全流程：以“疯狂动物城”风格为例

> **前言**： 本节重点拆解如何利用AI工具制作一部**奇幻动作短片**（以《疯狂动物城》同人预告片为例）。课程涵盖了从剧本生成、分镜设计、数字人配音到剪辑合成的全链路SOP，并特别介绍了如何利用 **香蕉模型 (Banana Model)** 保持角色多角度一致性。

## ⚡️ 核心知识速查

### 🛠️ 工具箱与核心功能

| 工具                 | 核心用途        | 关键技巧/模型                           |
| ------------------ | ----------- | --------------------------------- |
| **豆包 (Doubao)**    | **剧本/分镜生成** | 生成结构化脚本，拆分“静态画面”与“动态视频”提示词。       |
| **极梦AI (Jimeng)**  | **画面/视频生成** | 核心工具，支持**数字人对口型**（让静态角色说话）。       |
| **TypeNow / 香蕉模型** | **角色一致性**   | 生成角色的**九宫格多视图**（正面/侧面/背面），用于后续垫图。 |
| **剪映 (CapCut)**    | **剪辑与特效**   | 画中画合成、添加音效/字幕、朗读功能生成旁白。           |
| **MiniMax**        | **语音合成**    | 辅助生成高质量的角色配音。                     |


### 💡 关键提示词公式
```
 [景别] + [角色/主体] + [动作描述] + [环境/场景] + [风格后缀]
```
- _示例_：`特写镜头，朱迪警官，看着天空，惊恐表情，疯狂动物城风格`
    
- **IP优势**：对于知名IP（如疯狂动物城、柯南），AI模型自带知识库，无需详细描述外貌，直接输入角色名即可。
    

## 📼 实战案例：制作《疯狂动物城3》预告片

### Phase 1: 剧本与分镜 (Scripting)

**Step 1: 生成剧本**

- **工具**：豆包
    
- **提示词**：`帮我写一个《疯狂动物城3》的预告片剧本，要求节奏紧凑，包含悬念。`
    
- **优化**：将生成的文本拆解为 **[画面内容]** 和 **[视频动态]** 两部分。
    
    - _画面_：朱迪站在市中心。
        
    - _动态_：天空逐渐变暗，乌云密布。
        

### Phase 2: 画面与视频生成 (Asset Generation)

**场景 A：新闻播报（数字人应用）**

1. **生成底图**：提示词 `树懒主持人，坐在新闻台前，疯狂动物城风格`。
    
2. **生成配音**：准备好台词文本（英文/中文）。
    
3. **合成视频**：使用极梦的 **“数字人”** 功能 -> 上传底图 -> 输入台词 -> 选择音色（如中年大叔音） -> 生成。
    
    - _注意_：如果需要更丰富的情感，可使用MiniMax生成音频后上传。
        

**场景 B：复杂动作（拆解法）**

- _错误示范_：提示词太长包含多个动作（“朱迪站在市中心且徽章震动”），AI容易混乱。
    
- _正确做法_：**拆分镜头**。
    
    1. 镜头1：特写，徽章震动。
        
    2. 镜头2：全景，朱迪站在人群中。
        
    3. 后期剪辑拼接。
        

**场景 C：多角色对话（过肩镜头）**

- _难点_：AI很难精准控制“牛局长对着朱迪说话”的空间关系。
    
- _技巧_：
    
    - 使用 **“过肩镜头” (Over-the-shoulder shot)** 提示词。
        
    - 若生成失败，简化为 **“朱迪和尼克的背影”**，侧面表现正在听任务。
        
    - 提示词示例：`室内场景，朱迪和尼克的背影，面前是严肃的牛局长，疯狂动物城风格`。
        

### Phase 3: 角色一致性进阶 (Advanced Consistency)

**痛点**：如何让角色在不同镜头里长得一样？ **解决方案：香蕉模型九宫格 (Banana Model)**

1. 在 TypeNow 平台选择 **香蕉模型**。
    
2. 上传角色基础图。
    
3. 生成 **九宫格视图**（包含左侧、右侧、背面、正面等9个角度）。
    
4. 下载这些切片图，在极梦中作为 **“参考图” (Image Prompt)** 使用，生成连续镜头。
    

### Phase 4: 剪辑与后期 (Editing)

**Step 1: 声音设计 (Sound Design)**

- **环境音**：添加马路嘈杂声、警报声（增强真实感）。
    
- **BGM**：
    
    - 前半段：悬疑/紧张音乐（配合乌云密布）。
        
    - 转折点：激昂/史诗音乐（配合主角出场）。
        
- **对齐**：调整视频速度，确保口型和语音时长大致匹配。
    

**Step 2: 视觉合成**

- **画中画**：将“新闻播报”视频缩小，放在大屏幕素材的角落，模拟电视新闻效果。
    
- **转场**：使用“乌云层”视频作为转场过渡，连接城市与天空岛场景。
    
- **字幕**：使用黑底白字（剪映图形库 -> 黑色矩形）制作电影感的中断式字幕卡（如 `This mission is very important`）。
    

## ⚠️ 避坑指南

1. **敏感词规避**：`警徽` 可能会被系统拦截，建议改为 `徽章`。
    
2. **风格统一**：每一条提示词末尾**必须**加上 `疯狂动物城风格` (Zootopia style)，否则画风会乱跳。
    
3. **多段拼接**：不要试图用一个长提示词生成整个故事，AI目前做不到。必须**分镜头生成**，最后靠剪辑连贯。
