# 🎬 AI情感短片创作全流程：从零打造2.5分钟新海诚风大片

> **前言**：本节课是AI视频创作的高阶实战，我们将整合前四节课的知识（分镜、运镜、生图、后期），完成一部完整的AI情感短片。课程将以一个“秒速五厘米”风格的爱情故事为例，详细拆解从剧本灵感、分镜表生成、角色一致性控制，到多人物对话视频生成及最终剪辑的全链路SOP。无论你想做治愈系、亲情类还是宠物拟人视频，这套流程都是你的核心武器。

## ⚡️ 核心知识速查

### 🛠️ 工具箱与核心功能

| **工具**            | **核心用途**    | **关键技巧/模型**                              |
| ----------------- | ----------- | ---------------------------------------- |
| **DeepSeek/豆包**   | 剧本与分镜表生成    | 提示词需包含：`画面内容`、`景别`、`音效`、`AI绘画提示词`        |
| **极梦AI (Jimeng)** | 分镜画面生成 (生图) | **A9模型** (适合动漫/新海诚风)；`AG模式` (处理复杂手机聊天界面) |
| **可灵AI (Kling)**  | 视频生成 & 一致性  | **2.6模型** (多人物对话)；**O1模型** (主体功能保持角色一致)  |
| **MiniMax**       | 配音/旁白       | 免费语音生成，支持语速/声调调节                         |
| **剪映**            | 剪辑与合成       | `识别音频`自动字幕；画外音加`回声`特效                    |

### 💡 避坑指南：提示词与参数

- **多人物对话格式 (可灵2.6)**：
    
    - 语法：`左边女主 @撒娇女友: “台词内容”`
        
    - 注意：必须使用**英文冒号**和**引号**；视频时长过长会导致语速拖沓，需在剪映中**倍速处理**。
        
- **角色一致性 (Character Consistency)**：
    
    - **极梦AI**：一次性生成所有分镜可保持风格一致；分批生成需使用`引用`功能。
        
    - **可灵AI**：使用**主体 (Subject)** 功能，上传多视角图训练模型，生成时引用该主体。
        
- **FPV穿越机提示词结构**：
    
    - `画面起始于...` -> `由...突然出现` -> `划过...弧线` -> `急速拉升至...` -> `俯瞰...` (强调连续动作与空间变化)。
        

## 📼 视频全案复盘

### 📍 04:39 理论篇：情感短片的灵魂

核心定义：情感短片不只是堆砌画面，而是通过场景、人物和对话传递亲情、友情、爱情、孤独或成长等内核，引发观众共鸣。

主流类型：

1. **治愈系**：唯美画面 + 舒缓音乐。
    
2. **亲情类**：重逢、告别、AI复活亲人、拥抱小时候的自己。
    
3. **爱情类**：初恋回忆、异地恋、假设未分手。
    
4. **宠物拟人**：猫狗内心独白（如“橘猫吐槽”、“狗狗临终回忆”）。
    

### 📍 06:17 流程篇：五步成片法

1. **剧本创作**：来源可是真实经历、网文片段或直接由AI生成（提示词：`写一个1分钟情感短片，主题是...，大反转，口语化`）。
    
2. **分镜脚本**：使用AI将剧本转化为包含`画面`、`音效`、`绘画提示词`的表格。
    
3. **画面生成**：利用极梦AI生成基准图，使用局部重绘修正细节。
    
4. **配音/视频**：使用可灵生成对话视频，MiniMax生成旁白。
    
5. **剪辑合成**：剪映完成组接、配乐与字幕。
    

### 📍 13:06 实操篇：分镜画面生成的修图魔法

在极梦AI中生成画面时，难免遇到Bug，以下是**修正SOP**：

- **物品错误**（矿泉水瓶 vs 汽水瓶）：修改提示词为`可乐汽水瓶 + 交织动作`，重新生成。
    
- **时间转换**（白天 vs 黑夜）：利用`图片编辑`功能，保留构图，修改提示词为`时间段改为晚上，天空布满星星`。
    
- **去除文字**：使用`局部重绘`涂抹文字区域，提示词填`去除文字`。
    
- **复杂界面**：手机聊天记录等包含文字的画面，使用**AG模式**生成更精准。
    

### 📍 18:36 实操篇：可灵2.6 多人物对话视频

打破传统AI视频“哑巴”限制，实现声画同步。

- **操作**：在提示词中指定角色位置和音色。
    
    > `左边女主 @撒娇女友: “今晚真的能看到吗？” 右边男主 @播报音: “云层会在23点散开。”`
    
- **进阶**：支持唱歌、Rap，可添加环境音效（如`风声`、`碰撞声`）。
    

### 📍 25:26 实操篇：可灵O1 主体一致性功能

如何让主角在不同场景（雪地、列车、房间）中不换脸？

1. 进入`主体` -> `创建主体`。
    
2. 上传**主要参考图**（正脸）+ **多视角补全图**。
    
3. 填写智能描述，打上标签（人物/场景）。
    
4. 生成视频时，**引用**该主体，AI会自动锁脸。
    

### 📍 28:04 实操篇：FPV与长镜头的高级运镜

- **流星划过长镜头**：
    
    - 提示词技巧：使用**分段描述法**（起始于...穿过...到达...）。
        
    - **DeepSeek润色**：将粗糙描述发给DeepSeek，要求`润色为AI绘画提示词`，再填入可灵。
        
- **智能多帧连接**：
    
    - 上传4张关联图（望远镜 -> 转身 -> 俯瞰 -> 书本特写）。
        
    - 使用**智能多帧**功能，AI会自动计算中间过渡，生成丝滑的运镜视频。
        

## 🚀 关键实操步骤 (Actionable Steps)

Step 1: 智能分镜表生成 (DeepSeek)

复制剧本到DeepSeek，输入指令：

> 帮我生成自动故事的分镜时间表，需包含AI绘画提示内容、画面音效、对话、独白，并标注AI绘画提示词为中文。
> 
> 将输出的表格复制到飞书/Excel文档管理。

**Step 2: 基准画面生产 (极梦AI)**

- 使用 **A9模式** (新海诚风)。
    
- 输入提示词生成关键帧。
    
- 遇到瑕疵使用 **局部重绘** 或 **重新编辑** (Inpainting) 修复。
    
- _技巧：生成人物的三视图或多角度图，为后续环绕运镜做准备。_
    

**Step 3: 动态视频与配音 (可灵AI/MiniMax)**

- **对话场景**：使用 **可灵2.6**，输入对话提示词，生成声画同步视频。
    
- **空镜/动作**：使用 **极梦AI** 视频生成，或 **可灵O1** (引用主体)。
    
- **旁白**：使用 **MiniMax** 生成高质量旁白（如“温暖闺蜜”音色），调整语速至舒适区间。
    

**Step 4: 剪辑与氛围营造 (剪映)**

- 导入所有视频片段，按分镜表排序。
    
- **音频处理**：
    
    - 旁白添加`回声`特效（营造回忆感）。
        
    - 添加`环境音`（风声、列车声）增加沉浸感。
        
- **字幕**：点击`识别音频`自动生成字幕，选择文艺风字体。
