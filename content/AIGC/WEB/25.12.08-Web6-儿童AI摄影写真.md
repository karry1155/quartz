# 🦄 零基础打造奇幻儿童写真：ControlNet 姿态控制与重绘全攻略

**前言** 欢迎回到 AI 绘画课堂！本节课我们将解锁 Stable Diffusion 中最强大的插件——**ControlNet**。不同于单纯的“抽卡”，我们将学会如何通过 **OpenPose（姿态控制）** 锁定人物动作，结合 **Inpaint（局部重绘）** 和 **LoRA**，将一张普通的儿童生活照变身为梦幻的奇幻写真。无论你是想修整崩坏的手部，还是想无损更换背景，这节课都是必修内容！

## 📊 核心知识速查

### 1. ControlNet 关键参数表

| **参数名称**                | **功能描述**                 | **建议设置 / 注意事项**                                                          |
| ----------------------- | ------------------------ | ------------------------------------------------------------------------ |
| **控制权重 (Weight)**       | 决定 ControlNet 对画面的干预强度   | 默认 **1.0**。若画面过死板可调低，若姿态不准可调高。                                           |
| **介入/终止时机**             | 控制 Net 在生成过程中何时“出手”和“收手” | **介入 (0~0.2)**：越早介入构图越稳；<br><br>  <br><br>**终止 (0.8~1.0)**：过早退出可能导致姿态变形。 |
| **完美像素模式**              | 自动匹配最佳分辨率                | **建议开启**。省去手动计算分辨率的麻烦。                                                   |
| **预处理器 (Preprocessor)** | 提取图像特征（如线稿、骨骼）           | **必须与模型匹配**（如选 OpenPose 预处理，必须选 OpenPose 模型）。                            |

### 2. OpenPose 常用预处理器速览

> 💡 **小贴士**：带 **DW** 前缀的预处理器通常比标准版识别精度更高。

| **预处理器名称**        | **识别范围**     | **适用场景**               |
| ----------------- | ------------ | ---------------------- |
| `openpose_full`   | 全身 + 手部 + 脸部 | **最常用**，适合绝大多数全身/半身人像。 |
| `openpose_hand`   | 仅身体 + 手部     | 不需要脸部轮廓约束时使用。          |
| `openpose_face`   | 仅脸部          | 专注于面部表情迁移。             |
| `animal_openpose` | 动物姿态         | 识别猫、狗、马等四足动物（目前精度一般）。  |

### 🛑 避坑指南

- **模型匹配原则**：使用 SD 1.5 大模型时，必须加载 `control_v11p_sd15` 系列模型；使用 SDXL 大模型时，必须加载 `xl` 结尾的模型。**版本不匹配会导致生成失败或报错。**
    
- **Liblib 平台差异**：Liblib 上的“起始步数/完结步数”对应 WebUI 的“介入/终止时机”。
    
- **预览习惯**：操作前务必点击中间的“爆炸💥”图标预览骨骼图，确认 AI 正确识别了姿态后再生成。

### 📍 00:00 - 02:14 课程引入与目标

### 📍 02:14 - 11:59 ControlNet 界面与基础操作

- **界面布局**：位于 WebUI 底部，支持多单元（Multi-ControlNet）同时开启。
    
- **低显存模式**：显卡性能不足（如 <8GB 显存）时建议开启。
    
- **预览模式**：
    
    - **开启预览**：窗口一分为二，左侧原图，右侧生成特征图（如骨骼图、线稿）。
        
    - **重要操作**：上传图片后，**必须点击“爆炸”图标**生成预览，否则系统无法获取控制信息。
        
- **风格匹配**：
    
    - **写实风**：选择写实线稿提取器。
        
    - **动漫风**：选择带 `animate` 标识的预处理器（如 `anyline_animate`）。
        

### 📍 11:59 - 24:15 OpenPose 姿态控制详解

- **核心功能**：通过识别关节点（肩、肘、膝、手腕等）来“冻结”人物动作，从而在换装、换背景时保持姿势不变。
    
- **特殊场景处理**：
    
    - **肢体重叠**：当手脚交叉时，普通处理器易识别错误，推荐使用高精度的 `DW OpenPose`。
        
    - **编辑骨骼**：点击“编辑”按钮，可手动拖拽骨骼节点修正错误姿态（如把识别错的左手改回来），完成后点击“发送姿势给 ControlNet”。
        

### 📍 24:15 - 29:00 ControlNet 局部重绘 vs 原生图生图

- **对比测试**：
    
    - **原生重绘**：容易受底模影响，皮肤质感有时与原图割裂，光影衔接生硬。
        
    - **ControlNet Inpaint**：使用专门的 `inpaint_only` 或 `inpaint_lama` 预处理器。**优势**：融合度更高，边缘过渡更自然，且支持更高的重绘幅度（Denoising Strength），能大幅改变内容同时保持画面统一。
        

### 📍 29:00 - 41:33 实战：儿童 AI 写真全流程

- **核心思路**：图生图（定基调）+ 蒙版（选区域）+ ControlNet（锁姿态）+ LoRA（加风格）。
    
- **Liblib 平台演示**：
    
    1. **模型选择**：收藏并加载“麦菊写实”大模型。
        
    2. **涂抹蒙版**：利用浏览器缩放（Ctrl+滚轮）精细涂抹需保留的脸部、手部。
        
    3. **姿态约束**：启用 ControlNet，上传同款原图，选择 OpenPose 锁定动作。
        
    4. **风格化**：加载“小龙猫”LoRA，权重设为 0.7，一键生成梦幻背景。
        

## 🛠️ 关键实操步骤：打造奇幻儿童写真

本案例将普通女孩照片转换为“小龙猫”主题的奇幻写真，同时修复手部细节。

### Step 1: 图生图基础设置

1. 进入 **图生图 (img2img)** 界面，上传原片。
    
2. **大模型选择**：推荐 `麦菊写实` 或其他写实类模型（配合 LoRA 效果佳）。
    
3. **蒙版绘制**：
    
    - 使用画笔工具，**涂抹需要保留的区域**（如脸部、手部、腿部）。
        
    - _技巧_：按住 `Alt + 滚轮` 放大画布，精细处理发丝和手指边缘。
        
4. **重绘设置**：
    
    - 蒙版模式：**重绘非蒙版内容**（即保留涂抹处，重绘背景和衣服）。
        
    - 重绘区域：**整张图片**。
        
    - 重绘幅度 (Denoising strength)：**0.75**（给 AI 足够的发挥空间）。
        
    - 尺寸：设置为 **512x768** 或 **768x1024**（竖图）。
        

### Step 2: 启用 ControlNet 锁姿态

1. 展开下方的 ControlNet 单元，勾选 **启用 (Enable)**。
    
2. **上传参考图**：再次上传同一张原片。
    
3. **配置参数**：
    
    - 控制类型：**OpenPose**。
        
    - 预处理器：**dw_openpose_full**（精度更高）。
        
    - 模型：`control_v11p_sd15_openpose`（确保是 1.5 版本）。
        
4. **预览检查**：点击“爆炸”图标，确认生成的彩色骨骼图与人物动作一致（尤其是手指）。
    

### Step 3: 添加 LoRA 注入灵魂

1. 在提示词框中点击 LoRA 选项卡。
    
2. 选择 **小龙猫主题儿童写真** LoRA。
    
3. **权重调整**：建议设为 **0.6 ~ 0.8**。
    
    - _提示_：`<lora:xiaolongmao:0.7>`。
        
4. **提示词**：输入正向提示词（描述场景、光影）和负向提示词（NSFW, bad hands 等）。
    

### Step 4: 生成与微调

1. 点击生成。
    
2. **观察结果**：
    
    - _背景单一？_ -> 增加场景描述词或更换 LoRA。
        
    - _手部崩坏？_ -> 检查蒙版边缘是否涂抹完整，或提高 ControlNet 权重。
        
    - _风格不像？_ -> 提高 LoRA 权重或重绘幅度。
