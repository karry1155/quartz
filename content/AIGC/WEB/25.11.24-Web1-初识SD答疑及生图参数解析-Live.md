## ⚡️ 核心知识速查 (Quick Reference)

### 1. 🛠️ 核心参数与模型对比

| **维度**   | **Midjourney (MJ)** | **Stable Diffusion (SD)** |
| -------- | ------------------- | ------------------------- |
| **性质**   | **闭源** (类比 iOS)     | **开源** (类比 Android)       |
| **使用方式** | 官方平台，选版本 (V6/V7)    | 本地部署/云端，可训练/修改模型          |
| **核心优势** | 审美在线，上手极快           | 极高可控性，生态丰富，支持 LoRA 微调     |
| **商业模式** | 付费订阅                | 免费开源 (本地)，云端平台 (部分付费)     |

### 2. 🧬 主流大模型版本避坑

| **模型版本**         | **发布时间** | **特点关键词**         | **适用场景/避坑指南**                                |
| ---------------- | -------- | ----------------- | -------------------------------------------- |
| **SD 1.5**       | 2022     | 生态最全，配置要求低        | 入门练习，注意手指/脸部易崩坏                              |
| **SD XL**        | 2023     | 构图/光影提升，理解力强      | 进阶创作，需 8GB+ 显存                               |
| **Flux.1 (F.1)** | 2024     | **当前画质天花板**，黑森林出品 | **⚠️ 不支持旧版 WebUI**，需用 Forge/ComfyUI 或 Liblib |
| **Qwen (千万)**    | 2024     | 阿里出品，中文理解强        | 适合中文提示词，国风创作                                 |

### 3. 💡 高频避坑 & 技巧

- **硬件门槛**：运行 **Flux.1** 推荐 **12GB-16GB** 显存 (4070/4080)；8GB 显存建议停留 1.5/XL 或转战云端。
    
- **Liblib 羊毛党**：免费用户每日 200 算力。**技巧**：注册两个号 (手机号+微信号)，用不同浏览器登录，每日可得 **400 算力**。
    
- **LoRA 搭配原则**：**基础算法必须一致**。即 SD 1.5 的 LoRA 只能配 SD 1.5 大模型，混用必报错！

### ## 📍 04:55 SD 与 MJ 的本质区别

- **直观感受**：MJ 画风华丽但“盲盒”感强；SD 功能面板复杂但“控制力”强。
    
- **底层逻辑**：
    
    - **MJ (闭源)**：官方“喂”什么你吃什么，像去餐厅点餐。
        
    - **SD (开源)**：给你菜谱和厨房，你可以自己做，甚至创造新菜系。
        
    - **生态扩展**：开源导致了 SD 生态的指数级爆炸（1变2，2变4），诞生了无数社区微调模型。
        

### ## 📍 06:55 “炼丹”：开源的终极浪漫

- **概念解析**：训练模型被圈内戏称为**“炼丹”**。
    
    - **大模型 (Checkpoint)**：相当于一本厚重的“百科全书”，通识能力强。
        
    - **LoRA (Low-Rank Adaptation)**：相当于一本薄薄的“专业手册”或“便签条”，专注于特定画风或角色。
        
- **风险提示**：训练失败被称为**“炸炉”**，参数调整需要经验积累。
    

### ## 📍 14:21 大模型进化史 (必看)

1. **SD 1.5**：老前辈，资源最多，但画手、脚容易出现“多指”或扭曲。
    
2. **SD XL**：画质显著提升，光影更真实，是目前的 **中坚力量**。
    
3. **Flux.1 (F.1)**：**版本之子**。由原 SD 核心团队出走后成立的“黑森林实验室”开发。
    
    - **⚠️ 关键注意**：F.1 **无法** 在传统的 SD WebUI (秋叶包等旧版) 中运行，因为 WebUI 内核已久未更新。想在本地跑 F.1，请切换至 **ComfyUI** 或 **Forge UI**。
        
4. **Qwen (千万)**：阿里的模型，最大优势是 **听得懂中文**，无需翻译提示词。
    

### ## 📍 33:14 大模型 vs LoRA：成本与应用

- **训练成本**：
    
    - **大模型**：需要 **数万至数十万** 张图，昂贵且漫长，普通人玩不起。
        
    - **LoRA**：只需 **几十张甚至一张** 图片即可训练。
        
- **LoRA 应用场景**：
    
    - **固定角色 (IP)**：把自家猫咪、偶像或原创角色炼成 LoRA，生成各种场景图。
        
    - **固定画风**：如“像素风”、“水墨风”、“无畏契约风格”。
        
- **职业前景**：Boss 直聘上已有“LoRA 模型训练师”岗位，薪资可达 20K，主要服务于电商（换模特）、游戏（出概念图）和文创公司。
    

### ## 📍 59:46 变现路径探讨

- **模型收益**：在 Liblib 等平台发布高质量模型，根据下载/使用量获取收益（官方激励计划）。
    
- **长期主义**：像“油条”、“DW”等头部作者，都是靠持续更新高质量模型稳居榜单。短期投机者很容易被淘汰。
    

## 🔧 关键实操步骤 (Practical Guide)

### 🎯 实操一：如何解决电脑配置不足 (Liblib 使用流)

1. **注册账号**：使用手机号注册 Liblib。
    
2. **获取算力**：
    
    - 每日登录自动获赠 200 算力。
        
    - **进阶技巧**：使用微信登录注册小号，配合不同浏览器（如 Chrome + Edge），实现 **双倍算力 (400点/天)**。
        
3. **选择模型**：在在线工作台，直接搜索并加载 **Flux.1** 或 **SDXL** 模型（无需下载几个 G 的文件到本地）。
    

### 🎯 实操二：正确搭配 LoRA (避免报错)

1. **确认底模**：先看你选的大模型是哪个版本（例如 SD 1.5）。
    
2. **筛选 LoRA**：在搜索 LoRA 时，务必开启筛选器，勾选 **"基础模型: SD 1.5"**。
    
    - _错误示范_：用 XL 的大模型去挂载 1.5 的 LoRA。
        
    - _结果_：生成出全是噪点或崩坏的图。
        
3. **调整权重**：
    
    - LoRA 权重一般推荐在 **0.6 - 0.8** 之间。
        
    - 过高（>1.0）容易画面过拟合（由如脸部崩坏），过低（<0.4）则效果不明显。
