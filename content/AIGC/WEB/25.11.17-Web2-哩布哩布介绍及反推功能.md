## ⚡ 核心知识速查 (Cheat Sheet)

### 🛠️ 高频功能键位表 (YBI界面)

| **图标/按钮**    | **功能名称**  | **核心作用**              |
| ------------ | --------- | --------------------- |
| 🔵 **蓝色小箭头** | **参数回填**  | 将参考图的提示词、种子、步数一键填入设置栏 |

### 📊 关键参数避坑指南

- **LoRA权重黄金区间**：`0.8 ~ 1.0`（<0.8 风格不明显，>1.2 画面易崩坏）。
    
- **SD 1.5模型尺寸**：推荐 `512x768` 或 `768x1024`（不要过大，否则易产生多头多手）。
    
- **SD XL模型尺寸**：推荐 `1024x1024` 起步。
    
- **加密模型**：带有🔒标记的模型仅限Liblib网页/客户端使用，**不可下载**到本地SD（如秋叶启动器）运行，否则会报错。
    

### ⚠️ 特别注意

- **F.1模型 (Flux.1)**：目前的YBI（WebUI）界面不支持，需使用ComfyUI或Forge环境。
    
- **算力消耗**：基础模型 < XL模型 < Flux模型；添加LoRA、高清修复会额外消耗算力。

## 🖐️ 关键实操步骤 (Actionable Guide)

### 实操一：如何正确使用LoRA模型？

1. **筛选模型**：在模型广场筛选“LoRA” + “SD XL” (或其他版本)。
    
2. **加入库**：点击模型卡片，选择“加入模型库”。
    
3. **启动**：点击模型详情页右上角的“去WebUI生图”（或者在YBI界面刷新LoRA列表）。
    
4. **配置**：
    
    - 确保左上角**大模型**与LoRA的基础算法一致（同为1.5或XL）。
        
    - 点击LoRA卡片，它会出现在提示词框中，如 `<lora:name:0.8>`。
        
    - **修改权重**：将冒号后的数字改为 `0.8` (推荐起步值)。
        
5. **触发词**：检查模型详情页是否有**Trigger Words（触发词）**，必须复制到正向提示词中才能激活效果。
    

### 实操二：本地SD如何安装下载的LoRA？

_(针对有本地显卡的用户)_

1. **下载**：在Liblib模型页点击“下载”。
    
2. **存图**：**务必**保存一张该模型的预览图，并重命名为与模型文件**完全一致**的文件名（方便在SD里预览）。
    
3. **路径**：将 `.safetensors` 文件和图片一起放入 `\sd-webui\models\Lora` 文件夹内。
    
4. **分类**：建议在Lora文件夹内新建子文件夹（如 `Style`、`Character`、`XL`）进行分类管理。
    

### 实操三：利用“灵感广场”一键同款

1. 进入“发现灵感”频道。
    
2. 找到一张满意的图片，点击进入详情。
    
3. 点击图片右侧的 **“复制生成信息”**（或者在YBI界面使用蓝色小箭头导入）。
    
4. **检查**：确保你“模型库”里有该图使用的大模型，否则会报错或自动替换为默认模型。
